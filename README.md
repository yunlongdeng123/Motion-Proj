# WorldSim project page

Static project homepage for editable 3D driving-scene reconstruction.

- Published at https://yunlongdeng123.github.io/Motion-Proj/
- Research code: https://github.com/yunlongdeng123/Motion-Proj/tree/research/worldsim-v8.2-drivingeditor-v44
- Deployment: GitHub Pages, `gh-pages` branch, root directory.

The included figures are actual experiment outputs. Reconstruction, road coverage,
and multi-view appearance fitting use separate evaluation protocols, stated on the page.
No external build dependencies are required.

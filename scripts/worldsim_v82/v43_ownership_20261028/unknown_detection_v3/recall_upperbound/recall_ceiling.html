组件与数据流
干预顺序
  1. 只移除既有 Actor，测量原 static 的可见贡献。
  2. 复放原候选剥离；在相同旧域内取消历史、深度与比例门槛。
  3. 按原 body 的固定规则扩域，一次去除初始可见行。
  4. 使用删除后的真实透射重算贡献，补删新显露行；不复用 before 权重。
逐阶段原行号集合、贡献积分和 SH 颜色闭合由原始产物记录。
结果边界
固定查询域内高斯贡献归零，是干预上界结果。它既不能说明分类器识别出了全部车辆，也不说明道路已补全；环境纹理仍进入完整原生 RGB。
没有改动冻结模型、SH 颜色或环境参数，没有修补后端，也没有把本轮干预权重生成训练标签。
当前仅三帧单场景；语义 PR、独立车辆影真值和跨场景迁移均未在此验证。原环境中的负值由线性 cubemap 查询保留，其与车辆影的对应关系待独立标注。

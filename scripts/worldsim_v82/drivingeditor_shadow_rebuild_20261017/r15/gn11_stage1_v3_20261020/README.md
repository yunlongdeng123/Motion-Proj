# 五身份 GN11 Stage-1 30K v3

该版本以五身份 GN11 30K v1 的真实输入/初始化协议和 v2 的道路来源、归属修复为基础。当前修订撤销 v2 的背景统一时间冻结：背景表示“不需要独立编辑的内容”，包含非目标运动物体；五辆目标车仍由共享动态分支承担。方法与四臂协议见下；当前执行状态统一见仓库 `docs/RESEARCH_STATUS.md`。

## 背景时间自由度：选择性正则

背景类恢复直接继承 `NativeGaussianModel`，保留 `_t/_scaling_t/_velocity` 的可训练参数、学习率、SHM 位置变化与时间高斯显隐。训练循环不再调用 `enforce_static()`，不会统一清零速度或强制所有点始终可见；原生时间梯度、时间 split 调度和 checkpoint/Adam 路径一起恢复。

可信稳定区域来自同一 raw89–137 的三维证据。CPU 构建 0.2 m 稀疏体素，每帧每体素只记一次；至少 3 帧、跨度至少 0.2 模型时间（实际约 1 秒）的重复非物体 LiDAR 表面获得置信度 1。所有车辆、行人、骑行者的真实三维框（包括不编辑的车辆）否决其体积内的稳定标签，避免停留一段时间的车辆被误认成固定设施；不建立额外 Actor。

已有 v2 道路查询中具有测量表面支撑、符合路面平面的几何体素获得较弱置信度 0.5。这只使用道路几何，不使用其 RGB 或来源开关；四组共同包含这一几何时间先验。道路薄层和车辆体积按三维高度区分，车身二维掩码不用于稳定标签、删点或压空道路 alpha。没有可靠证据的远车/表面保持未知。

| 背景 Gaussian | 时间行为与约束 |
|---|---|
| 可信重复表面（通常为道路、建筑、设施） | 原生 PVG 前向；较强的位移上界与窗口显隐正则 |
| 有几何支撑的遮挡道路 | 同样保持稳定倾向，但证据权重较弱 |
| 非目标车辆、远车或未知内容 | 保留运动和显隐；仅较弱的过拟合先验 |
| 五车当前实际渲染体积内的背景贡献 | 直接使用本次光栅化实际位置和有效 opacity 做归属排斥，合法路面薄层受保护；原生背景路径不施加动态自监督 time-shift |

运动正则直接使用原始速度决定的完整周期位移上界 `norm(raw_velocity) * T / pi`（换算米）；显隐项使用实际训练时间窗两端的平均 `-log marginal_t`。它们不读取会随寿命指数衰减的 feature velocity，避免大寿命藏住真实运动。稳定区两项权重各 0.1，上下文/未知区各 0.001，各域按有效点数归一且保留置信度减权；这是待训练验证的固定起始政策，并非已证最优系数。

每步按当前中心与尺度重新查询证据，大支撑（最大 sigma >0.2 m）不凭中心碰到稳定体素就整点强约束。clone/split/prune 后重新查询，无逐 Gaussian 固定标签可失配，也不添加 checkpoint 行状态。全图绝对时间/速度项由上述选择性目标替代；NPS 继续关闭，已有局部空间平滑保留。

[真实输入CPU覆盖统计](temporal_evidence_summary.json)：81,983 个重复表面体素、1,401 个有支撑道路几何体素；并集82,973，和物体否决区交集0。原585,943个背景初始化点中，中心匹配重复表面526,217、弱道路先验575、上下文/未知59,151；实际Gaussian还要经过尺度筛选。全部仅为证据覆盖，不是质量验收。

## 监督责任

| 目标 | 前向 | 参数责任 | 明确不做 |
|---|---|---|---|
| 车身最终合成 RGB | 真实 `I_joint`，不按真值掩码裁掉静态贡献 | 全部动态参数；背景几何/opacity（含 `t/scaling_t/velocity`） | 不给背景 SH 颜色或 EnvMap 车身 RGB 梯度 |
| 非法静态前遮挡 | 独立静态深度和 alpha，对比车身有效 LiDAR 深度 | 静态几何与不透明度 | 不用动态分支独自补偿静态挡车 |
| 动态身份泄漏 | 加入 EnvMap 之前的独立动态预乘颜色 | 动态参数 | 不把环境背景算作动态泄漏；不靠最终图像截断掩盖资产 |
| 道路恢复 | v2 冻结的真实同位置/异位置供体目标 | 仅静态参数 | 不直接更新动态或环境参数 |
| 拓扑细化 | 联合与独立分支各自屏幕梯度 | 对应静态/动态 Gaussian | 不把两套统计相加造成重复计数 |

车身联合项在真实联合图上计算：

\[
L_{body}=\ell(M I_{joint}, M I_{GT}).
\]

反向路由保留动态外观/几何对最终合成的责任，同时允许背景几何、不透明度及其时间参数移开错误遮挡；背景颜色不能从车身 RGB 复制车辆外观。静态前遮挡项使用 `static_depth_sum/static_alpha` 与有效测量深度的相对顺序，并按静态 alpha 加权。它能覆盖“中心在框外但宽投影侵入车身”的情况，但仍是屏幕深度代理，不宣称是逐 splat 的精确 front-alpha。

动态泄漏使用固定语义字段 `dynamic_premultiplied_rgb`：它来自独立动态光栅化，且位于 EnvMap 混入之前。在车身掩码膨胀 2 px 之外，损失同时包含区域均值与 top-1%，另处罚当前低动态范围约定下的

\[
\max(0,\lVert C_D\rVert_{\infty}-4A_D-1/255).
\]

原有完整动态掩码 alpha MSE、权重 100 保留，并在 v3 hybrid 路径中不再借用通用 opacity-entropy 开关作为是否启用的条件；没有增加显示阶段颜色截断。该字段只在固定黑色光栅背景下定义为预乘颜色，CPU/GPU 准入都会拒绝白背景配置。

## 分支增密

渲染器显式返回联合、静态、动态三套屏幕代理、可见性与投影半径。静态道路损失进入静态代理，车身联合项进入联合代理；每个 Gaussian、每个采样视图只记一次：

\[
g_i=\max(g_i^{branch},g_i^{joint}),\qquad denom_i\mathrel{+}=1.
\]

投影半径也逐点取最大值。原 30K 调度、静态/动态点数上限、SGCM 和完整动态 alpha 监督均不变。

## 四组固定对照

四组均为同一五身份 `a6/a37/a5/a26/a18`、raw89–137 共 49 帧、seed 0、fresh 第一阶段 30K、第二阶段 0；每 5K 保存。唯一变化是道路来源权重。

| 组 | 同位置真实 RGB/depth | 异位置供体 RGB/depth |
|---|---:|---:|
| `full` | 1.0 / 0.1 | 0.1 / 0.01 |
| `real_only` | 1.0 / 0.1 | 0 / 0 |
| `prior_only` | 0 / 0 | 0.1 / 0.01 |
| `ownership_only` | 0 / 0 | 0 / 0 |

控制器固定按上述顺序单路执行，最大并发为 1。每组先做真实 CUDA 前向/反向零更新 gate，再从相同 fresh seed 开始 30K。失败后保存现场并停止，不自动重试、不续训、不覆盖旧结果。

## GPU 与存储闸门

当前没有 `GPU_APPROVAL.json`，控制器即使被误调用也会拒绝执行。未来收到用户明确授权后，仍需生成与本方法/四臂范围匹配的审批文件，并显式传入 `--execute-after-user-gpu-approval`。

参考 v2 四组实际产物约 48.25 GB，v3 在启动控制器前要求 campaign 所在盘至少 70,000,000,000 字节可用；不足时状态写为 `WAITING_STORAGE_BEFORE_GPU_EXECUTION`，不会占用 GPU。单臂内部还会在启动和每个节点保存前重新做空间准入。

## 评价边界

最终必须按 `evaluation_contract.json` 的固定区域分别报告车身联合合成、车前静态遮挡、严格掩码外动态颜色、真实道路区、供体区、未知区和查询区外损伤。完整重建、静态、原始动态、alpha 和深度均需覆盖全 49 帧。训练完成、损失下降或保存节点齐全都不等于视觉质量通过，`human_verdict` 在人审前保持 `null`。

## 已知限制

- 静态前遮挡是 opacity 加权平均深度代理；若一条射线上前后多层静态贡献互相抵消，仍可能低估问题。零更新 CUDA gate 会先检查其梯度与数值稳定性，30K 后需用固定区域诊断确认。
- 颜色/alpha 比值上限只针对当前归一化低动态范围表示，不外推到 HDR。
- v3 同时修复多条共同机制，因此四臂只回答两类道路来源在同一 v3 条件下的覆盖作用，不能用于拆分每个 v3 修复项的独立因果贡献。
- 稳定表面标签来自有限分辨率的重复三维支持，不能保证覆盖所有固定物体；未知不会被当作稳定真值。跨时刻运动但缺乏标注的极慢物体仍可能形成重复支持，需要在非编辑内容的完整49帧回放中检查。
- 固定相机改变时间时，背景 RGB 允许变化；原来要求整幅背景时间差为0的 CUDA gate 已替换为原生 PVG 前向等价和时间梯度检查。固定表面的稳定性与非目标运动内容的保真度分别评价。

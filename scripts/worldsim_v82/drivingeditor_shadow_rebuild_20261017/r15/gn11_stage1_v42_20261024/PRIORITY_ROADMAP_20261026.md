# V42 路线调整：先验证外部先验接入，再验证道路后训练底座

2026-10-26。本文为方案评估与优先级更新，不是新的实验结果或已实现算法。FreeInpaint 尚未完成本项目 GPU 推理；TRELLIS 道路编解码、结构头和流模型后训练均未实施。`quality_accepted=false`，`human_verdict=null`。

建议采用用户提出的顺序：**先用 FreeInpaint 验证中心补全和编辑闭环，再用 TRELLIS 第一代评估道路专用后训练。** V42 是共享架构和验收协议；FreeInpaint 是首个候选后端，不能把 V42 等同于某一个外部模型。数据和防泄漏协议可同步准备，不需要等 FreeInpaint 全面成功或反复失败后才开始。

## 优先级与阶段产出

| P1 | FreeInpaint 官方推理与 V42 适配 | 外部先验能否产生可对齐、有用的中心三维道路，而非只有一张好看的图？ | a37/a6 中心支持、几何一致性、编辑可见贡献；已知道路挖洞对照 |

| P2 | TRELLIS 道路编解码适配 + 确定性中心结构/潜特征预测 | 通用物体潜空间能否忠实表示米制道路及标线？结构预测是否真正覆盖内部？ | 已知道路重建与留出中心测试先成立，再引入复杂生成 |

## 核验后的模型判断

**FreeInpaint：近期执行优先。**它是图像条件的前馈三维修补/重建路线，具有专用权重和高斯输出；DL3DV-10K 训练不构成道路中心能力证明。[官方实现](https://github.com/Rorisis/FreeInpaint)、[论文](https://arxiv.org/html/2610.11857v1)。本地固定源码 `9ac03f14b652c8d03d65f770bdf61da253da0fef` 的 `network/freeinpaint.py` 接收参考图、掩码源图和可选支持图；底层调用显式使用 `extrinsics=None, intrinsics=None`。现有封装重新预测相机，不能把相机参数放进 kwargs 就宣称使用了我们已有标定，也没有现成的“道路 Gaussian + 世界洞”入口。

**TRELLIS 第一代：后训练底座的首选候选，尚不能直接定版。**其 SLAT 与高斯解码器、权重和训练代码确实适合复用输出端；预训练对象以三维资产为主。潜编码输入是与空间结构关联的多视图特征，不是任意高斯参数表。[官方代码](https://github.com/microsoft/TRELLIS)、[方法](https://arxiv.org/html/2412.01506v2)。普通 image-to-3D 流程还包含去背景和物体裁剪，不适合直接处理作为背景的道路；应适配底层编解码与条件模块。**先证明路面能被忠实表示，再证明能补缺失。**

**WINGS：优先阅读和对齐的直接相关方法。**它已经实现结构补全、条件潜生成与场景解码适配；专用结构网络需要另外训练，论文使用了内部场景数据。本次未核实到完整官方复现包及专用结构权重，下载 TRELLIS 不能等同于复现 WINGS。[论文](https://arxiv.org/html/2609.37816v1)。可执行条件不足时，应把自建版本写成受其启发的对照，而不是冒充官方方法结果。

**TRELLIS.2：后置。**官方仓库已公开训练流程，不能因“没有训练代码”降级；当前后置的理由是 O-Voxel/网格/PBR 表示与既有高斯编辑系统的适配成本更高。[官方实现](https://github.com/microsoft/TRELLIS.2)。GPGS 等候选保留文献角色，当前不同时启动多条模型适配线。

## FreeInpaint 第一轮应怎样验证

1. 固定 a37/a6 的世界缺口、边界/过渡/内部核心，以及 raw102 的定位像素。核心域由缺口几何预先定义，不能根据生成成功的区域缩小；世界面积与累计像素分母分别报告。两辆车只是失败案例，不是泛化数据集。
2. 按官方入口验证可运行，再输入本项目图像与掩码。屏蔽目标车身和已知静态污染；保留可靠道路上下文与其他遮挡。参考图如由生成模型产生，须保存来源与种子，不能作为真实标签。
3. 用洞外可靠 RGB/LiDAR 几何建立尺度与刚体对齐，另留不参与拟合的锚点评价误差。若不同视角存在非刚性几何不一致，单一相似变换不能修复，必须记录失败。禁止用错误静态残影深度作为对齐锚。
4. 只取目标缺口及有限接缝带的候选几何，转成米制道路表面/高斯。每条候选保留模型、版本、坐标变换、生成标记与质量检查记录；模型置信分数不冒充校准后的正确概率。
5. 在独立编辑副本上做同 checkpoint 的四种只读组合：原静态、静态加候选、仅局部抑制已确认污染、抑制污染并加候选。另看候选单独的几何。这样才能分开补全效果与残影移除效果；这四种渲染不是四组训练。
6. 同时做“本来可见的道路、全洞撤源”的控制样本：撤去所有关联帧 RGB、LiDAR 和高斯条件，隐藏前证据仅用于评价。固定区域、样本数、种子及选择规则；有 GT 时比较中心几何/外观，无 GT 的真实中心只报告合理性、稳定性、贡献与人工判断。

FreeInpaint 若仅产生好看参考图，但三维尺度或多视角不成立，不能算 V42 成功。若候选几何成立而最终被黑色静态污染挡住，下一步是处理编辑副本遮挡，不能用继续训练生成模型代替。若适配和编辑都成立而中心内容/泛化不足，才得到最直接的道路后训练依据。首轮结果无论好坏，都应按这些失败类别收敛，避免无限调参。

## 对 TRELLIS 补充方案的具体调整

**保留全洞查询、全局条件和可见性状态，但先减少首版自由度。**在道路局部坐标中的薄表面带上布置覆盖整个洞的查询；中心从第一步就有训练目标，不依赖附近已存在的高斯。道路表面存在性与细节可以分开预测，不把整个路面下方当实体占据。低频坡度/高度优先受米制几何与连续性约束；不确定的外观和细节再由条件生成表达。路缘、多层道路等不满足局部单曲面假设的位置要单独标记，不能硬塞进一个高度场。

**先编解码，再确定性补全，最后流匹配。**首先检查已知道路的高度、法线、细标线、颜色和留出视角；编解码已有路面都失真时，不应归咎于洞内监督。随后用相同数据与条件做确定性掩码预测，检验结构头/中心监督；条件流只有超过这一基线，才能证明额外生成复杂度有价值。边界逐圈生成保留为后续对照，不作为中心必须经过的出生路径。

**不能任意改动预训练潜空间。**优先固定编解码/流的潜空间约定，训练输入条件适配器与道路结构头，必要时进行受控解码适配。若更新编码器，已有流模型和缓存目标潜向量的对齐可能失效，需版本化并重新验证或重算。特征训练前期可以使用可靠目标结构，随后加入预测结构的误差；避免硬阈值判空使中心永远没有特征梯度。

**道路坐标与模型尺度同时管理。**旋转、平移和单一尺度归一化可用于进入模型，同时保存可逆米制变换；不独立拉伸道路高度。解码后同步变换高斯位置与协方差、相机与表面量。以 64 单元横向网格为例，8 米 patch 的格距是 12.5 厘米：这只是分辨率算例，说明标线与微小起伏必须通过连续偏移/解码表达检查，不能因为输出是高斯就默认精度足够。

共享接口建议为：`complete_road(context, world_hole, evidence_state, cameras, metric_transform) -> hypotheses`。FreeInpaint 通过图像入口生成后再对齐；TRELLIS 通过道路条件和空间潜表示生成。两者均输出候选、来源、未知域与转换记录，复用同一编辑与验收代码。接口是设计约定，本次未实现。

## 数据优先级与泄漏控制

第一套数据优先选择已有可访问、标定完整的 RGB/LiDAR 路段；KITTI-360 是合理的原型候选，但不能把现有 KITTI 场景资产当作已经具备 KITTI-360 训练集。[KITTI-360](https://www.cvlibs.net/datasets/kitti-360/)。先跑通一种数据的道路清洗、场景划分和大洞目标；再优先加入 AV2 的几何条件与跨城市测试，之后扩充 Waymo。AV2 的 30 cm 地面高度图是**栅格采样间距，不是高度误差保证或精细道路真值**。[AV2 文档](https://argoverse.github.io/user-guide/api/hd_maps.html)。其他数据集后置，不在首版混合六种数据源。

人为隐藏但有可靠答案的道路，与真实遮挡未知区域必须分开。观测表面、射线已确认自由空间、未知区域分别编码；未知不能训练为空。Seen2Scene 的不完整扫描学习已有类似监督原则，不能把“区分未知”单独当作创新。[Seen2Scene](https://arxiv.org/abs/2603.28548)。

严格基准先按路段/场景划分，再生成 patch 和洞；输入先撤源、后渲染/编码。删除中心 token 但保留完整图编码、跨界大高斯、全场景优化后渗透到周围的特征，均可能泄漏答案。完整重建的目标可作标签，输入表示必须从经过遮挡的条件独立构造；若复用已看过目标的 V1 上下文，只能标为编辑测试，不能声称整系统从未见过隐藏道路。真实车后暴露样本还须处理光照、曝光与投射阴影，不能把车底黑影监督成永久道路颜色。

## 论文主张与验收

SLAT、查询 token、双向注意力、流匹配与高斯解码的组合不足以构成新贡献。值得检验的是：在真实观测不完整的前提下，**道路米制结构和可见性条件是否帮助模型生成大洞核心；这种先验是否跨路段泛化；生成支撑与局部污染抑制是否共同改善最终编辑。**这些目前是研究假设。

最小比较包含已有曲面/纹理延拓、FreeInpaint、相同道路条件的确定性预测和条件流版本；按可用资源再加入忠实复现的相关方法。关键消融是道路后训练、中心监督/查询、可见性条件和污染抑制；不因设计列出它们就启动额外训练。

评价按距洞边界的米制距离分层，中心损失/指标单独归一化；报告完整核心分母、表面误差、法线、自由空间侵入、留出视角外观、接缝以及最终道路实际贡献。单纯增加 opacity、扩大高斯覆盖、提高独立补丁美观均不能替代这些结果。真实未知中心没有 GT，不能制造 PSNR。

完整重建采用固定 [V41-B 基线](../../../../../docs/V41_B_BASELINE.md)，编辑副本独立载入。用户接受的约 0.19 dB 全图/0.274 dB 车辆 ROI 等跨运行经验波动尺度不用于豁免主副本被改动，也不掩盖局部车身破坏。固定 master 的身份和原生输出通路应保持；论文统计方差另需重复实验，当前不扩预算。

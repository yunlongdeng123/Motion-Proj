# Scene008 a6 保留侧高斯重表达

以[上一轮逐帧保护的共享退役版本](../scene008_a6_residual_replay_20261105/README.md)为基线。相机、原始 10K、道路 1K、PVD、车姿和已通过的门控冻结。黑底主实验与街景复核均为 49 帧。新增训练更新为 0。

~~~mermaid
flowchart LR
  A["上一轮 a6 与固定 PVD"] --> B["残余遮挡 αT 足迹"]
  O["固定下部与保护域"] --> B
  B --> P["车体坐标的共享保留侧平面"]
  P --> R["单高斯或三片重表达"]
  R --> G["黑底逐帧保护和街景复核"]
~~~

按当前剩余遮挡归因，登记 6,658 个候选。使用下部遮挡足迹和实测／非目标支撑的车体坐标质心确定每行分隔平面。单高斯采用截断分布的条件矩。三片用保留侧的三个等概率区间分别计算条件矩，并以条件质量和轴向方差调整峰值透明度。两组使用同一候选池、平面、分组搜索和保护合同，各自选择通过的子集。

保护沿用实测 RGB、LiDAR 深度、覆盖和非目标检查。非目标变化相对 38.3% 的祖先融合计量，以限制跨轮漂移。另限制各帧的固定下部显露率相对最新基线最多下降 1 个百分点。使用 PILOT 105、113、130 优先拒绝违规组合。固定下部显露指标仍是联合贡献除以独立 PVD 下部透明度。

| 黑底版本 | 下部显露率 | 已观测 RGB MAE | 深度 MAE (m) | 非目标 RGB 变化 | 保护失败帧 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 上一轮共享退役 | 47.97% | 0.018739 | 0.269847 | 0.002597 | 0 |
| 单个保留侧高斯 | 48.90% | 0.018739 | 0.269877 | 0.003114 | 0 |
| 三片保留侧高斯 | 48.37% | 0.018732 | 0.269949 | 0.003050 | 0 |

单高斯选中 1,111 个登记行，三片选中 833 个。各帧受时间掩码及分隔相对位置约束。全候选单高斯在 raw130 触发深度保护，三片在 raw113 触发非目标 RGB 和显露保护。有限的分组搜索下，三片收益较小，使用单高斯结果复核街景。隐藏面缺独立真值。

删 a37 的街景显露率 45.91% → 46.84%。显露道路 MAE 0.0222073 → 0.0222073，无编辑可见 a37 RGB 配对差 3.7e-08。同一份保留侧表达用于两种状态。

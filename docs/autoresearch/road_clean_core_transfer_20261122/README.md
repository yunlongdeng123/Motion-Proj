## 先区分评分mask、核心行与实际核足迹

旧source gallery渲染core加halo，并在整个图上展示RGB／alpha；低alpha尾部会因此更醒目。截图中的固定评分mask还排除了外围与低覆盖像素。此前r2实际迁移已经只使用core行，不能把本轮写成首次丢弃halo。

本轮直接将source00的1598行、source02的900行核心保存为标准RoadRows可读取的road.npz，halo行均为0。源组件实际渲染采用黑底预乘RGB及中性灰背景RGBA合成，不在彩色图上套2D评分mask。另存alpha与诊断mask，仅用来解释指标。

原色组件与父资产中同一批核心行的原生黑底RGB逐值相同；NPZ重新加载后实际渲染也逐值相同。源00原色在110／137、源02原色在100／110／115／117的内缩高alpha评分域，均未检出photo色度99.9分位加0.10阈值以上的像素。校正00和八帧修复02作为真实对照保留，不默认把颜色拟合版认定为更适合迁移。

# 固定道路表面的覆盖驱动局部增密

本轮真实追加6,168个道路高斯，另启用3,108个既有锚点。认证道路上的覆盖缺口明显减少，但黑缝尚未全部关闭，教师细节质量也未通过整体验收；当前资产不晋升默认场景。

## 新增了什么

父资产是新1152教师拟合后的普通高斯 `road_common1152_20261121/formal/r3/G_NUMERIC/asset`。道路总行数588,861→595,029，活动行数151,988→161,264。旧892个“新增活动点”仅是历史锚点激活，不计入本轮真实追加。新追加路径覆盖所有道路行字段及来源台账，并通过公开加载器验证N+M；旧观测/材质来源记录保持，新增颜色不标成实拍观测。

初版候选保留但未用于GPU；正式位置、法向及曲面资格复查后为3,108个旧锚点和6,189个追加候选。启用锚点并训练覆盖200步后，只根据实际alpha残差一次选出6,168个追加点，剔除21个已不需要的候选。新点颜色来自父资产邻近合格道路，不直接复制教师作初始化。

所有位置、法向与法向厚度固定。覆盖阶段有限训练新启用/新追加点的不透明度和两切向尺度：先锚点200步，再追加后400步，合计600。外观阶段冻结覆盖，以实际普通高斯渲染训练颜色1200步；旧许可颜色修正限制±0.05，新颜色限制[0,1]。原活动点的几何与覆盖、相机、车辆、静态场及教师继续冻结。

教师固定为1152×768、T0 step600、legacy、seed101。raw86/110拟合，134/179/198诊断；没有新扩散推理、共享网络或TRELLIS训练，也没有超参数搜索。资产继承历史观测，不是盲测。

## 剩余缺口的固定诊断

旧canonical无交点不等同于颜色只读限制。已有冻结LiDAR平面及测距锚点可独立再认证：锚点Delaunay内部、最近距离≤1.5m、三角最大边≤3m、平面残差≤0.05，保持原门不放宽。348个旧节点重新通过认证；对C像素仅恢复225/319个ray-hit，剩余5,934/7,077个二维编辑像素没有足够认证，不能断言全部属于待补道路，也不靠任意平面强填。

另外执行了固定乐观足迹诊断：旧活动点不变，新增两组opacity设1、切向尺度取各自原cap，仅5次原生道路前向、0更新，正式资产与训练账目不改。opacity1略放宽了训练上界0.999，因此不作为生产状态；全图存在少量非单调数值差异，不称严格逐像素上界或3DGS容量证书。

在同一认证最终残余像素上，C的1,055/737个alpha<0.05像素在该诊断下仍全部无支持，其中1,026/710个新增组贡献精确为0。C薄覆盖207/263个中仅3/63个达到0.95；S剩余43/63个则全部达到0.95。这说明C主要需要进一步区分当前采样未触达与保护约束，S的薄尾可由覆盖目标/正则或有限优化解释，不能统一追加训练步数。旧拒绝日志只有聚合K拒绝数，尚不能逐像素归因具体K约束。

## 保护、保存与限制

真实新增16行的工程短程覆盖opacity及两切向轴各自非零梯度、Adam/RNG状态恢复、覆盖到外观入口和公开持久化重载。覆盖恢复下一步差4.77e-7，外观2.13e-7；重载RGB差1.49e-8、alpha差2.98e-8。由真实短程估算正式队列约359秒，采用不足一小时的完整短生命周期资格；71秒工程smoke独立记账，不冒称10分钟，也不用于正式热启动。

正式结果的五帧保留车辆联合RGB/alpha最大变化均为0，无屏幕K像素回贴。该结论只覆盖这五帧。域外联合RGB并非全部不变：MAE约0.0030–0.0041，最大局部变化约0.21–0.50；实拍确认道路相对父资产RGB变化MAE约0.00283/0.00362。未将这些变化自动判为退化或收益，整体画质不自动晋升。

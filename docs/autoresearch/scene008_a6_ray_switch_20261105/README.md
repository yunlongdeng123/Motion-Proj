# Scene008 a6 车体半空间裁剪

承接[保留侧高斯重表达](../scene008_a6_truncated_support_20261105/README.md)。同一组原生 10K、道路 1K、固定 PVD、相机、轨迹和评价射线。主实验只画黑底 a6，街景独立复核。新增训练 0 步。

~~~mermaid
flowchart LR
  G["冻结高斯与车体坐标平面"] --> R["相机射线的保留侧质量"]
  R --> A["缩放原生 alpha、沿用深度排序"]
  P["固定 PVD 与道路"] --> A
  A --> E["49 帧实测、非目标与显露保护"]
  E --> O["黑底与街景复核"]
~~~

隔离构建同一源的 CUDA 前向扩展，现有环境中的原生光栅器未被替换。对每个被登记的原生高斯，计算相机射线上高斯质量落于车体保留半空间的比例，再缩放原生二维 alpha。半空间在车体坐标跨帧共用。解析式使用整条直线的条件高斯并对精度矩阵作数值条件保护。深度排序和深度辅助输出仍沿用原生中心。本实验的 alpha 改动不提供不透明表面首交保证。

裁剪关闭时，49 帧 RGB、alpha、深度及标签与原生路径逐项一致。单高斯独立解析对照的 alpha 最大误差 1.46e-06；全保留和全裁掉测试精确通过。固定域仍为 26,229 个像素，采用同一批独立下部 PVD 透明度分母。沿用实测 RGB、深度、覆盖和非目标保护，并限制每帧相对父版的显露回退至多 1 个百分点。非目标变化相对 38.3% 的融合祖先计量。

给 48.90% 父版叠加裁剪时，单组搜索没有找到通过组合。按上一轮原生行与同一平面替换矩匹配近似时，322 行通过，全部替换触发 5 帧非目标保护。本轮有界选择留下了中央遮挡。79,146 条有证据的空射线与已有原生支撑的非目标保护像素无重叠；无法从该负证据判定这部分混合支撑可以退役。

49 帧街景共用同一套半空间行。删 a37 的下部显露率 46.84% → 47.93%，道路 MAE 0.0222073 → 0.0222070；无编辑的可见 a37 RGB 配对变化 6.9e-09。该结果是同场景读出，未观测表面缺独立真值。

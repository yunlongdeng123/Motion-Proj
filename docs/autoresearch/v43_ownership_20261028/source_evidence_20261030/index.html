如何据此推进V43

  1. 将“身份不确定”和“编辑后显露的几何/外观证据不足”分别记录。隐藏错误道路表示不应被强行归类为car；归属正确也不保证其颜色和形状可信。
  2. 候选审计包含编辑后的实际可见贡献，并回查所有原观测和稀疏测量；不再只用删前权重封闭候选。
  3. 未来表示修复须依据单一表面支持拟合位置/协方差，并重新解释外观；跨帧保持与编辑监督分别核验。均值移位、统一缩小、继承父色只保留为失败控制。
  4. 在证据充分但仍失败的部分，才比较只归属与可学习联合修复；原观测从未提供的信息，单列为先验/补全问题。环境与车关联阴影仍独立登记。

以上为一个机制场景的来源和证据诊断；不代表真实场景泛化，不训练新的分类器，也不将特权颜色诊断包装为算法。AutoDL保持开机。

下一步最小可辨识协议及停止条件：固定表示的统一路由只称真值辅助可行性参考；有限穷举只能证明其受限子问题，不能证明全局不可能。

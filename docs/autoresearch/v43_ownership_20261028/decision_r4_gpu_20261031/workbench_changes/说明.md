# 工作台改动

补丁包含共享入口、候选页代码、首场固定帧对照、两份维护规则和八张本轮真实输出图；不包含旧图像资产。`changes_manifest.json` 提供目标路径和逐文件 SHA256。

复现时保留已安装工作台资源，并将 `actor_screen_existing/existing_normalized_v1` 与 `actor_screen_horizonforge` 放在同一个结果根目录下。使用 Python 运行：

```text
python install_workbench.py --platform-root <共享平台目录> --legacy-root <旧道路平台目录> --results-root <V43_R4_GPU_20261031目录> --backup-dir <新的备份目录>
```

安装器校验补丁哈希，重建15场候选数据与90张预览，备份已有目标后再写入。静态检查见相邻 `actor_candidates/static_qa.json`；没有浏览器交互验收。`build_registry.py` 可从同一结果根目录重建车辆登记及准备队列，其结果只表示准备顺序，非正式资格或编辑成功。

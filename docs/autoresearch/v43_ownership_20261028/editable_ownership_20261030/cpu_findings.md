# 场景一：分类证据与可编辑表示的 CPU 科学审计

本轮检查冻结 static30K 的 918,850 行与 Actor10K 的 6,241 行，覆盖 raw77–125 共49帧，并连接 raw98/113/114 的既有原生贡献、独立背景和表面见证。结果支持继续检验“稳定归属＋有深度支持的子高斯分解”，尚未验证该表示能够安全编辑。分类器准确率本轮没有独立真值可测；即使后续分类准确，现有整行操作仍需要单独验收。[完整字段、分母与复现参数](cpu_audit.json)；[28个复核候选](review_candidates.json)。

![既有 V43 architecture components 图](architecture.svg)

沿用既有组件图定位原始观测、归属证据、资产与编辑接口；本轮只审核已保存数据，没有执行图中的新训练或新渲染。

同一行可以同时承担不同屏幕域的贡献。以 actor-omitted 冻结 static 的原生 alpha×T 为口径，要求目标 body 贡献占该行总质量超过0.05，且弱背景域绝对贡献质量超过0.05，三锚点分别得到46、88、103行。这个门限是诊断工作点，背景域仍为弱证据；数量不代表三维可分性或分类精确率。

| raw | 双域贡献候选行数 | 复核 static ID | 目标贡献比例 | 弱背景贡献比例 |
|---|---:|---:|---:|---:|
| 98 | 46 | 826517 | 0.2768 | 0.4171 |
| 113 | 88 | 829555 | 0.2629 | 0.3133 |
| 114 | 103 | 575102 | 0.4194 | 0.4823 |

这些例子说明，给整行一个语义或实例标签，仍不能表达只移动/移除其中的目标支撑、同时保留道路支撑。若把整行判为车再整体删除，原生操作也会作用于其背景贡献；把整行判为路保留，则无法单靠标签消除目标相关外观。该证据尚未判明两域贡献各自对应正确的车、路三维表面，因此需要检验有真实深度支持的两侧子高斯，而不能把候选直接当作拆分真值。

既有整行控制提供了操作层面的负面证据：`native_target_contact_smoke_r1` 在 raw98/113/114 的 `remove_u` 分别移除9,961/6,848/6,442条 static 行，目标域扩张2像素以外仍有10,217/17,921/18,610个像素的平均通道RGB变化超过1/255。这是历史冻结GPU控制，本次没有重跑；它并非“分类已完全正确”的实验，也不是背景真值误差，但说明旧候选与整行操作尚未满足局部编辑保护要求。[历史原生控制记录](LOCAL_WORKSPACE_REFERENCES.md)。

帧状态必须与持久行状态分开。Actor 的默认 core 是本帧可见、已有预测类别14–19且5px轮廓带贡献比例低于0.2；raw98/113/114的 core 分别为2,511/2,665/2,546行，49帧始终满足的只有1,855行。static 中371,406行曾有保存的可见贡献，547,444行未被该导出观察；56,082个持久行在不同帧曾分别获得 road 与 vehicle 预测。后一个数是跨帧冲突行数，不能解释为同帧两类真值，也不能据缺测给其补负标签。路由文件用255区分“本帧未观察”和已观察但 `class_id=0` 的语义弃权。[逐行观测分区](LOCAL_WORKSPACE_REFERENCES.md)。

R2记录的是干预选择。49帧中73,102条 static 行曾被选中，其中65,563条在某帧曾有 road 预测；raw98的独立背景保护候选870863也进入了当前R2集合。它有3个源观测、匹配源对77/88，但仍未取得认证无阴影背景标签。这些冲突要求保留证据和未知态，不能用R2 membership监督最终owner，也不能把road预测直接提升成背景真值。

混合支持、颜色冲突和阴影effect需要独立字段。三锚点“有背景几何见证但SH颜色不符”的行数为39/46/41，与上述46/88/103个同帧双域贡献候选不是同一集合；它可能反映外观污染、视角模型或其他误差。阴影则是原始同世界道路观测的光度暗化与随动证据，应记为道路receiver上的目标关联effect，保留road语义。它既不是car实例归属，也不等于几何混合；源阴影缺测不能充当nonshadow标签，现有认证背景行数仍为0。

旧static父中心也不能直接硬绑到车辆canonical坐标。对同一22,305行，在三锚点相对raw113的最大位移中位数为世界坐标0.273m、车辆canonical坐标13.913m；没有一行在后者更稳定。这只说明旧父中心轨迹没有随目标运动，不能排除其包含目标外观贡献。下一步应在真实LiDAR或已核验可见表面上建立子高斯深度与canonical约束，保留两侧支撑，并分别检查无编辑重建、仅编辑car子高斯后的道路损伤，以及road effect的变化。当前 `quality_accepted=false`、`human_verdict=null`；新增训练、GPU与SSH调用均为0。

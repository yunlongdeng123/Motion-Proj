受控仿真核验的范围

在已有单个程序化世界的真实原生GPU上，新增28份控制输出：原绑定基线，以及纯绑定错误、位置偏移、SH常量颜色、仅环境辐射、时间接错、前向区域点群移除六组副本。原检查点不改。颜色控制保持alpha/深度不变；环境控制保持C_G/alpha/深度不变；纯绑定错误的none与基线一致。9项约束不变性检查通过。

这是部分E1控制，不是全因素评价规则的完成验收，也不是自动根因分类器的准确率。形状/尺度的全部变化、独立多物理表面高斯、物理阴影/反射和完整未见背景控制仍未完成。点群移除只检验表示容量混淆，不证明完整真实车头。未使用独立编辑GT评分，不能冒称完整奖励误判率验证。

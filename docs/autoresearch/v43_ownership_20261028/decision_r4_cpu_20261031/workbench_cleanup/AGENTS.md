# 共享场景诊断平台维护规则

- 共同入口仅保留场景导航和简短使用说明，每个场景只有一个入口链接。
- 页面使用清楚的中文；顶部不放研究状态、执行日志、仓库路径、版本进展横幅或难懂的工程缩写。
- 影像、三维几何、时间轴和基本操作优先展示；采样、语义、归属等高级选项放入可展开区域。
- 实验报告、roadmap、status、研究设计与阶段简报在对话中单独交付。未经用户授权，不把这些内容或链接加入本平台及场景子页。
- 保留真实实验组、原始资产、正反案例、已有控件和诊断记录导入导出功能。历史组在现有实验选择器中查看，不通过新增横幅重复链接。
- 候选可视化只表达输入证据和待核验集合，不能冒充真实归属、编辑收益或人工验收。
- 修改前保留备份；修改后检查本地引用、必需控件、ID 唯一性和脚本语法。交互验收受限时如实记录，不把静态检查称作浏览器验收。
- 不在页面中自动追加每轮报告。重新生成页面时同样遵守这些规则。

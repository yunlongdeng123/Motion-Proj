核对方法与证据边界

对 11 个演示首帧与 11 个候选做 121 对比较，直接按比例缩放原始 JPEG，无裁剪；使用像素 MAE、灰度 SSIM / NCC 及 ORB–RANSAC 几何内点。每个编号的自身候选均排名第一，SSIM 为 0.9212–0.9794，与次名差至少 0.2179；阈值是诊断筛查设置，未标成经过校准的错误概率。

035 的四个视频帧分别在 198 个原帧中匹配到同号索引，SSIM 为 0.9328–0.9583，内点至少 1,745。其余十场本轮只核对首帧，没有声称完整时序或全部 109 个任务已逐项验收。图像分析仅确认来源，不提供编辑后真值、R4 资格或可编辑能力结论。

十个缺失场景从既有公开 Waymo 镜像的固定版本读取首条 TFRecord：20 次严格 Range 响应，检查 Content-Range、长度、masked CRC32C 和 protobuf 内嵌 context。累计有效载荷 60,103,165 字节；测得记录大小后，将原估算 50 MiB 调整为 80 MiB 上限，实际使用 57.318 MiB。没有完整下载这十段，也没有重建、训练或 GPU 调用。

校验指向固定第三方镜像记录的一致性；未验证官方发布方签名或这些完整文件的 SHA256。首记录 payload 未留存，保留了原 JPEG、读取收据与固定对象地址；独立审核重新计算了图像指标和请求总账，没有再次下载 payload 重算 CRC。

阴影为什么不仅慢，而且算错

物理协方差的最大条件数约2.38×10⁸。FP32构造的矩阵已有11个非正定，显式求逆后的对称部分有8个非正定。实现又把积分二次型中的a和横向距离clamp为正，错误可能以有限的巨大光学厚度出现，普通“loss和梯度有限”检查不会发现。

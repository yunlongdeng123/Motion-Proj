## 定位可见归属问题

a18独立rawbodyalpha约0.97，全场景中属于自己的可见贡献只有0.81498。完整43身份贡献追踪显示body域静态层质量1928，其中道路363；另有其他Actor贡献324。静态贡献不是自动的错误归属证明，正常遮挡、测量和边界仍需区分。该静态部分加权尺度相对锚点0.642，不支持泛称道路高斯尺度膨胀，更不能按高度裁掉车底。

原可见身份MSE按完整known-HWK平均，小车体域及多个空实例可将内部监督大幅稀释。独立内部rawalpha可接近1，却未能保证全场景自身可见。这与已经修复的独立raw内部、完整图外部项不同。

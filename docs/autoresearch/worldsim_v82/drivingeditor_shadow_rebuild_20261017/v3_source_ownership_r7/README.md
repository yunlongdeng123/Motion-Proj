## 直接追溯原始测量

框内不自动等于车体。复用实际49帧标定、已知轨迹，仅46训练帧：逐条真实LiDAR投影，已知body内且与真实深度一致者进入canonical车体证据bank；已认证重复世界道路点进入canonical道路源点bank，保存frame_index、原LiDAR行号和canonical坐标。没有生成mask或点，没有用测试RGB构造方法。

a37初始17134个种子中，2729精确匹配已认证道路源点（canonical容差2e-5米），1337精确匹配已知可见车体源点。后者只是已知相机标签覆盖的子集，其余不能自动判道路。其他Actor的道路精确匹配也保留在初始化审计。不能将该子集当成黑影真假整体比例。

只读初筛使用nearest16估计高斯体积内车体／道路支持，其局限已登记，不能直接作为删除标签。实际修复对每个候选查询4σ最大半径包围球中的全部真实车体点，再算精确Mahalanobis距离：有4σ内车体支持则保护；有至少3帧、质量>=0.5的自车或其他车RGB贡献也保护。必须有至少3个canonical源时刻实际道路正证据、当前高斯中心在6cm内且道路点在3σ内；再选择一条已至少3时刻世界道路支持的实际LiDAR世界点重锚，保留完整出处。没有正道路证据的未知／遮挡点保持原身份。

在R6已有426转归属之后，新增1431点通过：a5=34、a12=140、a25=19、a26=28、a37=1210；a6没有正道路源点bank、a18无足够新支持，均未裁切。车体体积／RGB保护计数与拒绝项见source_ownership_summary.json，完整逐点证据仍在实际产物路径。更新静态道路的局部实测几何、邻居和跨时刻参考；实际观测RGB初始化，有可信重复亮簇时才改用伪参考。没有固定平面、灰色补洞或冻结车辆位姿造道路。

另检验投影最长轴可能遗漏横跨短轴的轮廓，新增任意轮廓法向切面：多视角实际mask交点、真实道路邻近和至少3帧方向一致；21父点分为42子点且两侧保留。多变量截断高斯保持总体均值／协方差，26CPU检查通过。它是边界分解适配，未声称完整复现SAGD。

零SGD时同7帧E3@7000对E2@7000车身MAE最大绝对变化3.7e-5，根代理看图未见明显轮胎／车身损失；仅足以允许1000步受界优化，不是资产干净度通过。

# Scene008 道路颜色校正

承接[车体半空间裁剪](../scene008_a6_ray_switch_20261105/README.md)。在同一份原生 10K、道路恢复 1K 和固定 PVD 场景中校正道路颜色。两种编辑状态共用一个世界坐标颜色场。冻结车身、道路几何、透明度与深度排序。重建训练新增 0 步，网格系数由约束最小二乘拟合。

~~~mermaid
flowchart LR
    A["冻结场景与道路高斯"] --> C["联合光栅化的道路贡献"]
    B["原始 RGB 与跨时刻道路观测"] --> D["拟合世界坐标颜色网格"]
    C --> D
    D --> E["无编辑与删 a37 联合渲染"]
    E --> F["49 帧与 9 帧留出检查"]
~~~

依据联合光栅化的 alpha*T 输出精确线性响应。比较 3 参数全局偏移、90 参数 6×5 网格和 297 参数 11×9 网格。细网格插值粗网格后拟合残差，节点颜色校正限于每通道 ±0.09 sRGB。两种状态共用 703,067 条有效像素观测。九个同场景视角 89、95、101、105、113、121、125、130、137 排除在本轮拟合之外。

| 道路 RGB MAE | 原场景 | 全局偏移 | 6×5 | 11×9 |
| --- | ---: | ---: | ---: | ---: |
| 49 帧无编辑 | 0.032733 | 0.032665 | 0.031878 | 0.031688 |
| 49 帧删 a37 | 0.022207 | 0.022056 | 0.019433 | 0.018912 |
| 9 帧留出无编辑 | 0.032148 | 0.032077 | 0.031266 | 0.031080 |
| 9 帧留出删 a37 | 0.023213 | 0.023067 | 0.020265 | 0.019722 |

采用 11×9 方案。无编辑接缝带 MAE 0.036475 → 0.035575，删 a37 接缝带 0.066526 → 0.058440。49 帧逐帧道路保护通过。重放 98 张图的深度、alpha 和各层贡献逐像素一致，已观测 a6 RGB 一致。下部 PVD 街景显露率仍为 47.93%。删车道路评价采用同场景重新观测到的道路，隐藏区域缺少独立真值。

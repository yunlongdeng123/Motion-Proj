从剩余遮挡登记 7,686 行，按下部前缀贡献相对于已观测、LiDAR 和非目标支撑排序。约 98.7% 的已登记前缀贡献属于在非目标域也有可见支撑的行。逐帧检查真实原生渲染，沿用实测门槛，并限制下部提案域及一像素边缘以外的原生支撑区变化，平均 RGB 差 ≤ 0.005，平均累计透明度差 ≤ 0.01。通过保护的 1,390 个新增退役行跨 49 帧共用。有界排序前缀和 12 组补试限定了搜索范围。

显露率以独立 PVD 下部透明度为分母。只保护实测的诊断会改变其他车身区域，全候选退役还会伤到已观测车身，两组均只作为对照。隐藏区缺独立几何真值，结果衡量同场景读出。

街景共用同一门控。删 a37 后，下部显露率 36.36% → 45.91%，显露道路 RGB MAE 0.022191 → 0.022207。无编辑时，可见 a37 的配对 RGB 差为 3.9e-08。raw113 中央仍有遮挡。

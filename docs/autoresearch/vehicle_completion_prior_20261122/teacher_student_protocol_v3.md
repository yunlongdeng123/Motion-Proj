## 数据与职责

真实 RGB、实例可见区域、相机、轨迹和有效测距约束当前 a20；冻结的生成教师只为缺失表面提供候选。教师输出可为网格、占据／距离场或高斯，并提供同一对象坐标下的深度、法向、轮廓与多视角材质渲染。学生是带身份、轨迹绑定和表面约束的对象高斯。

BUILD 仍用 raw86／110；raw134／179／198只作真实诊断。当前近同向后视帧不能视为密集360度观测。教师合成视图可以用于蒸馏，但不进入真实观测数量或真实精度验收。

## 先保住可见车身，再补缺失表面

先建立可信的观测表面锚点及颜色来源。原生高斯中的大足迹和背景污染需清理，不能把全部 owner21 行直接当作可信车身。保护的是校准后的真实观测证据及通过核验的表面，不是未经核验的原始高斯参数。

在 canonical 表面上维护观测区与缺失区。生成器可提出完整对象候选，进入资产时只提取缺失补片；补片需与观测表面衔接。二维遮挡掩码与三维缺失表面分别保存，不能用整张投影盒代替精确遮挡关系。教师与真实可见部分发生冲突时，以真实证据为准。

## 灰模门必须在材质与学生训练前

四项分别给出证据和判定：部件连接关系；轮位、轮轴与接地；真实可见轮廓；实测点／射线贴合。另检查可见几何与颜色保护、生成写入仅在缺失域。缺证据和待核验均不视为通过。任务阈值须结合传感器噪声、投影分辨率及物理尺寸明确登记，不补造通用通过线。

检查已融合观测面的整车灰模，至少展示前、后、两侧、顶、底及真实相机投影。浮块、占位轮胎、错误车身比例和接缝未通过时返回几何环节；网格非空、贴图齐全、Alpha高不能替代该门。

若教师天然联合输出形状与外观或直接输出高斯，先只消费几何并渲染灰模。已生成的外观可以原样归档，但灰模通过之前不进入材质优化、外观蒸馏或道路联合训练；原生输出格式不构成跳过验收的理由。

本轮 Omni 整车替换候选未通过这项验收。既有材质及400步仅作为诊断结果保留，不晋升为合格先验。

## 蒸馏必须包含训练目标

初始化只给学生起点。灰模通过后，分开记录真实观测损失与教师蒸馏损失：

`L = L_real_visible + L_real_range + λg L_teacher_geometry(U) + λs L_teacher_silhouette(U) + λn L_teacher_novelview(U) + λf L_teacher_feature(U) + L_surface_constraints`。

几何项约束学生表面／占据／法向与已验收教师补片；轮廓项约束预定相机下的缺失区轮廓；新视角项从同一冻结三维教师渲染，对颜色、深度与法向作蒸馏。语义／特征项按证据加入，不能替代形状验收。各项仅对许可缺失域 `U` 生效，真实可见几何与外观锚点受保护；接缝单独约束。

实测射线的命中和已知自由空间分开使用：未采到点的地方不自动为空。合成视图自一致性只证明学生接近教师，不能证明隐藏车身真实。实际梯度需从高斯光栅化结果返回许可学生参数；教师网络冻结。

学生参数按来源分组：通过核验的观测区固定几何和真实材质锚点；缺失区允许表面约束的位置／协方差、不透明度与材质参数接受蒸馏。几何、轮廓与足迹需要实际参与优化或重采样，不能只训练颜色再将其称为三维形状蒸馏。轨迹、相机及其他实例先冻结，接缝处另设观测保护约束。

车辆资产先验收，再进入道路联合渲染。道路教师损失对车辆参数梯度为0，车辆真实损失对道路参数梯度为0；原生残影遮挡另行诊断。当前已跑的“先验初始化＋可见RGB拟合”没有上述完整几何／新视角蒸馏，不命名为完整教师蒸馏闭环。

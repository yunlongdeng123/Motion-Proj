## 算法

1. **来源核验。** 199帧原始影像按位姿、道路几何、可见性与光度门限形成同位置支持库。目标C/S域严格支持在86帧为0，在110帧为4像素；拟合稳定性门后使用其中3像素。可见邻接带A另计，不把它算成车下同位置观测。缺少直接支持的位置转入高斯路块迁移。
2. **参考块检索。** 在现有资产中按真实来源支持、清晰度、车辆与阴影排除产生多尺度候选；用原照片与原生隔离高斯渲染的颜色、高频对应和覆盖进行资格核验及排序。17个提案、4个合格、空间去重后3个；实际原生核验2个，自动选取其中得分较高的0.8米源块，核心1598个高斯。历史source标签不直接证明当前RGB仍为实拍，当前外观另经照片核验。
3. **局部保距配准。** 源、目标的局部坐标系分别为 Bs、Bt，目标法向和高度由已有合格道路支持的鲁棒中位数确定。R=Bt·Bsᵀ；每行 μ'=R(μ−cs)+ct，Σ'=RΣRᵀ。位置相对关系、三主轴尺度、RGB和不透明度整体携带，保留源块。法向和完整四元数同步旋转；不逐点随机拷贝颜色，也不拉伸微三角形的几何噪声。
4. **重叠归属。** 0.8米块按0.6米间隔放置，4厘米世界格以中心代价与Potts邻接项进行4轮局部ICM归属，一格选一块，不对RGB取平均。它是局部离散优化，不是全局最优图割。目标核心旧道路退役，8厘米外边界按光学厚度分配新旧不透明度；实际原生渲染再筛除改变保护区的迁入行。
5. **有限局部拟合。** 新路块共享1个曝光增益和3个RGB偏置；只放开54046条接缝行的不透明度及共同切向尺度倍率。全部位置、法向、法向尺度、四元数、旧参数和新核心形状冻结。用实际照片A带及合格同位置见证监督颜色，固定认证C/S域监督覆盖，正式预算400步，不追加搜索。

源块、目标域和所有阈值来自数据与配置；运输核与归属核使用通用数组接口。本轮只验证065同街段，输入适配器仍绑定该次场景资产。概念参考为[3DGS](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/)、[GaMeS](https://arxiv.org/abs/2402.01459)和[Image Quilting](https://people.csail.mit.edu/billf/www/papers/efrosFreeman.pdf)；这里的配准、来源筛选和原生保护门为本实验实现，不是上述工作的复现。

另行固定的A邻接带（仍属86/110 BUILD视角）的RGB MAE，原资产/零步/拟合在86为0.02256/0.02793/0.01851，在110为0.02694/0.02703/0.02443。梯度MAE在86为0.01583/0.03614/0.02369，拟合仍弱于原资产；110边界接缝跳变均值为0.01676/0.01098/0.02704，拟合后回退。边界指标与实图共同表明，颜色拟合下降没有转化为整体无缝质量。

原认证C域内α<0.95的像素，原资产/零步/拟合在86为809/1334/1207（分母26456），110为303/2450/1893（分母53300）。这项覆盖指标明确未超过原资产；不能只用零步到拟合的改善为迁移方法判成功。

逐行来源记录包括源资产、原高斯ID、源/目标坐标、块ID、刚体变换、归属及后续参数变化。报告分层提供可信实拍输入支持、参考材质、迁入高斯实际原生贡献和继承/迁入最终贡献。输入支持图不等同于历史材质因果归属；继承层不按旧/新先后强行标为实拍或生成。

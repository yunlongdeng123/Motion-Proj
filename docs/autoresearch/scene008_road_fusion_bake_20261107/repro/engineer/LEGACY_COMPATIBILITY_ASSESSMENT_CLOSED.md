# Legacy road colour proposal: CPU assessment, not executed

The existing evidence has full49 masks and group-level RGB/alpha, but no complete per-native-Gaussian49-view road/guard/vehicle/unknown contribution certificate. No nonempty safe static set has been established. Dark group3 colour or a centre near the ground is insufficient. Root therefore closed this route before GPU qualification or fitting; its native forwards, optimizer steps and original-layer updates are all zero. C fixed10pixel edgeblend is the sole actual posthoc control.

If this were considered in a future authorized scope, a sidecar row-ID RGB delta added after the frozen native SH/time-dependent base could preserve the base function without editing native SH coefficients. It would need stable row/world geometry, legal colour intervals across49 views and actual native contribution purity in both states, including covariance filtering, cutoff and early stop. A mixed footprint would remain frozen. Such a certificate is absent here, so no claim of safe legacy intervention or legacy bottleneck removal is made.

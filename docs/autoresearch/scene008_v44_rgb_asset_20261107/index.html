异常评估

现象已有证据v44 的处理与边界
蓝紫色道路、局部颜色割裂RCR-1 在原生 10K 补回联合 RGB×1；历史旧 M2 配对中，raw113 原框绝对蓝色误差 0.084625→0.003897，raw137 右斑 0.074090→0.004888。用户已采用该去蓝结果。复用已有原生 10K 与它自己的新道路、行号和 gates。新车体会改变遮挡，历史数字不能冒充 v44 效果。
车底／车后银灰亮片历史 raw137 的 315 亮点中，静态 premultRGB 净亮化约 +0.3311；环境×T 约 −0.19285；a6／a37 为 0，道路接近 0。环境×T 仍含车形结构；这些点在既有道路接管范围外。去蓝未解决该项。新组合输出同一次排序下各层真实 RGB 与 alpha×T，先复查静态层与环境；不扩车体或任意删高斯掩盖亮片。
既有暗团／阴影样斑块此前 raw105 暗核主要为近道路的黑色旧静态前缀，raw113 底边暗核主要为道路基底 RGB；没有独立物理投影阴影层。保留为独立问题，不把银亮片、暗团和蓝斑合成一个成因，也不宣称换车体已经修复背景。

历史道路 target 是跨时刻重观测 proxy，始终遮挡区域没有独立删车 RGB 真值。315 亮点是旧版本诊断选区，不作为新版本评价分母。

接线规则

  • 版本独立：运行入口、契约、输出和代码统一使用 v44；RCR-1 是去蓝组件来源，v43 及更早现场不覆盖。
  • 车体保持：canonical 资产 45,314 行，C2 后验与固定 RGBA 不训练；SurfaceLOD 按相机采样，保留／删除状态共用同一车体数据。
  • 背景完整成套：新原生模型必须配它自身重建的道路 1K、contributors 与 gates；预检拒绝旧静态行号串入新模型。
  • 色场边界：原 11×9 色场在旧 M2 联合场景校准。首版仅作冻结世界坐标残差迁移，保留源绑定及新绑定；没有伪称重新标定。
  • 成像一致：原生 a6 从输入物理移除；所有剩余层进入同一次 native Gaussian 深度排序，删除操作只移除 a37，不切换背景旁路。

## 0. 执行摘要与不可改变的决定

### 0.1 只做一个任务，不做三种论文

**主任务：已知标定、身份与刚体轨迹下，从稀疏构建观测重建可复用的对象规范坐标表面。**

输入：构建窗口内的稀疏 LiDAR、测量射线、标定、对象尺寸/身份与已知轨迹；相机输入作为统一可选信息，在第一轮主竞争中关闭。

输出：每个对象的一份米制显式表面 `S_i`，可同时执行最近点、真实最近射线交点和已知刚体位姿复用。一个对象不得为不同评价射线临时生成不同几何。

最终部署查询：

$$
Q(S_i,o,d)=\inf\{t>0:o+td\in S_i\}.
$$

无交点返回未命中；证据不足另记未知状态。未知不得计为已证实空闲，不得从评价分母悄悄消失。

**不同时承担：纯视觉米制恢复、运动预测、交互式反事实真实性、完整强度/多回波/丢失返回建模、闭环驾驶收益、实时 GPU 仿真器。** 显式导出与刚体复用是合同，不是单独创新。

### 0.2 本轮明确允许离线逐资产求解

为避免同时追求高难度共享模型泛化与高精度几何，本轮采用：

> 可共享学习先验 + 仅使用当前对象构建观测的离线重建/优化 → 固定显式资产 → 在线几何查询。

共享网络只在 FIT 数据学习；对新的开发/测试对象，可以用其 **build 观测**做方法规定的资产求解，但不能使用该对象的留出真值。这是逐资产重建协议，不是零样本前馈协议。

原 V7.3 冻结前馈模型可作为历史对照，但主比较必须包含相同离线信息与合理求解预算的强基线。不能把额外的实例优化收益全部归因于新算法。离线求解不等于必须有大网络：若胜者是有效的几何算法，也允许按几何算法论文组织。

### 0.3 淘汰规则

三个候选独立并行完成一轮最小证据包。允许修正明确工程错误；不允许用新方法假设、额外骨干、宽阈值搜索或挑选种子救失败者。

- 三个均失败或证据不足：写明 `NO_SURVIVOR`，冻结本轮 V7.4，不自动生成第四种方法。
- 一个通过：冻结核心机制，进入扩展验证。
- 多个通过：先保留最多两个，在扩展开发集直接竞争，最终只选一个论文主方法。
- **三个都不过，不能把它们拼起来冒充一个“完整框架”。**

### 0.4 不恢复的旧方法族

V7.1 的 primitive-union/透明度并集物理化、删除式安全、M39 返回头微调不恢复；V7.3 的 loss-weight/alpha 网格、掠射角透射、无支持组件整片删除、靠更大视觉骨干解释所有失败不恢复。

本计划允许新的表面重建表示，但不允许把已经关闭的后处理删面方案换名。A、C 中的域选择/基元选择必须是受正观测约束的**重建变量**，可保留、替换和构造支撑；不能读取测试早面标签后删面，更不能删除对象条目。

以上为本轮核对的最接近来源，不是“全学术界查无同类”的证明。若实施中发现更近论文已经包含核心机制，立即记录并淘汰或重新提交研究决策；不硬改叙事。

### 2.2 三个候选为什么都按方法级投入

- **A 改变求解单位**：从独立面/独立射线局部更新，改为共享域约束冲突所驱动的成组支撑交换。
- **B 改变优化对象与约束表达**：从对当前硬首面的分支求导，改为在分片线性场中同时约束整段射线与返回零点，且导出使用同一场的精确等值面。
- **C 改变支撑生成机制**：从固定数量的片不断膨胀/收缩，改为由全局未满足观测及侵入代价驱动的按需几何生成。

三者分别研究“已有支撑如何重组”“几何如何直接满足观测”“缺失支撑如何出生”。A 的成功不是 B、C 的前提；C 不能偷偷调用 A 的新求解器后再宣称独立成功。

## 3. 公共数据合同、评价与信息预算

### 3.1 四种数据角色

| 名称 | 用途 | 是否允许影响模型或资产 |
|---|---|---|
| `FIT` | 学习共享先验、训练提议网络、一次实现参数定标 | 允许；只能是训练日志 |
| `BUILD` | 某个待重建对象的输入观测 | 允许用于该对象的离线求解 |
| `DEV_QUERY` | 开发对象中未用于构建的时刻/视角 | 仅评价与候选选择，不能进入该对象求解器 |
| `FINAL_QUERY` | 方法冻结后独立日志中的留出观测 | 只作最终评价，不再选方法/阈值/训练轮数 |

训练日志的额外帧可以作为 FIT 监督；开发/最终日志的留出返回不能伪装成“见证”送回求解器。查询接口只接收 `o,d,time`；真实距离由评价器单独持有。

V7.3 已曝光的 5 个 nuScenes DEV 日志和 20 个 AV2 日志，从现在起可作为开发资源，**不再当未曝光确认集**。不强制跨数据集零样本：主结论允许在严格独立的同分布日志上成立；跨域结论另设测试，不隐瞒已知 AV2 失败。

### 3.2 第一轮最小真实队列

预先按输入元数据选择 8 个已曝光开发日志：优先原 5 个 nuScenes DEV 日志 + 原 AV2 队列中按固定 ID 顺序选取 3 个日志。每日志抽取 6 个构建可用对象，共约 48 个；按构建点数量分层取样，目标包括极稀疏、一般稀疏和较充分三类，不按任何方法的输出挑选。

另将这些日志的缺输入对象作为合同检查队列，完整保留在总账；不把“只在构建可用对象上的方法比较”冒充全体对象结果。没有留出自有返回的对象可进入覆盖/资源统计，其自有射线指标记未定义并报告数量，不能记零误差。

`probe_cohort.json` 一次写出真实 ID、输入窗口、点数分层、数据集及测量可用性。本计划不捏造现成 log ID 或未取得的数据。如果实际无法组成该队列，以全部可用日志和真实样本量报告，不按结果补选。

### 3.3 单对象输入与求解预算

- 沿用既有构建窗口，不给某个方法额外全轨迹输入。
- 初始优化可使用固定抽样的自有返回与邻近对象框的自由段观测；候选接受与最终导出后，必须回查全部可用 BUILD 射线。抽样只能加速，不能把未抽到的违规当安全。
- 原始标定和轨迹只读。没有逐返回时间戳的数据，按原协议明确标注时间近似；不虚构更精确的去畸变。
- 只有确认符合当前近似的可靠返回才能成为硬见证。多返回模式、框归属代理、玻璃/混合像素、冲突测量分别记录，不宣称原始返回都是理想几何最近面。
- 测距容差 `epsilon_obs` 在 FIT 上依据数据协议统一确定，三方法相同；评价命中带沿用 ±0.2 m。评价容差不是传感器噪声标准差。
- 第一轮主竞争不使用 RGB、DPT、可学习透明度或 ray-drop；保留胜者的视觉扩展接口，不将跨模态增量设为必须成功的第二主线。

### 3.4 公共输出限制

同一个导出网格完成所有硬查询。默认主预算为最多 4,096 个三角形；最多另报 16,384 面预算的容量曲线，不能用高密度版本替换低预算失败结果。

若方法无法在主预算内输出，不做未评估的后处理简化；报告预算不满足。更大表示只有在精度—成本前沿确有价值时进入后续扩展，不因模型大而加分。

所有输出记录原生基元数、导出三角形数、面积、有效对象数、构建时间、峰值内存、查询时间。不能只匹配导出面数而隐去庞大的候选库/隐式场/学习先验成本。

### 3.5 主指标

完整保留 V7.3 评价器定义，避免名字相同而分母改变：

`hit / early / late / miss / free intrusion / directed distance / recall@0.2m`。

此外记录：

- `any-correct-intersection` 与 `early-with-later-correct-support`；
- 构建见证保留率、违约残差、弃答/未知比例；
- 合成真值上的双向几何精度、面积/密度与自由段误差；真实稀疏端点不冒充完整表面 GT；
- 按输入点数、视角覆盖、动态状态和数据集分层；不能只挑一类漂亮切片。

按对象归一、日志等权报告配对差。场景级结果另算分母，不用背景多数掩盖对象退化。构建约束满足不等于留出查询正确，两张表必须分开。

## 4. 候选 A：共享见证交换式表面重建（WEX） ★★★

### A1. 唯一主假设

**固定某一条射线的责任面，或逐射线贪心切换，会把本来可行的共享表面修复锁死。根据共享域约束的冲突，成组交换支撑责任，可以在保住必要交点的同时裁去提前交点。**

A 不是“再给 r7 加一个 mask”。从原始 BUILD 观测生成承载曲面，再学习共享域与必要几何调整；任何测试射线均查询同一份最终表面。冻结 r4/r6 只用于可选诊断，不是唯一输入资产。

### A2. 表示与候选计算

用 `K` 个开放承载曲面：

$$
S(V,b)=\bigcup_k \psi_k(\{u\in D_k:b_k(u)\ge0\};V_k).
$$

第一实现采用已有局部曲面解码的结构作为初始化接口：64 个承载片、每片 4×4 几何顶点；域函数在独立共享 UV 网格上分片线性表示。共享边只生成一个裁剪交点。所有方法参数均以米制评价。

承载曲面初始化优先用 BUILD 点的局部平面与共同 LiDAR 几何先验，不读取留出点。几何先验来源、训练预算与点到面转换必须列出。A 对照使用完全相同的承载曲面和域分辨率。

对每条 BUILD 射线，与**未裁剪承载曲面**求全部候选交点 `(face, k, u, t)`。一片可以对应多个交点，不能按“每片最多一个交点”实现。

定义：

$$
\mathcal F_r=\{j:t_{rj}<t_r^*-\epsilon_{obs}\},\qquad
\mathcal G_r=\{j:|t_{rj}-t_r^*|\le\epsilon_{obs}\}.
$$

正确硬首交点要求：

$$
\forall j\in\mathcal F_r:b(u_{rj})<0,\qquad
\exists j\in\mathcal G_r:b(u_{rj})\ge0.
$$

这是观测合同，不是新物理定律。前者是全称约束，后者是析取约束。未知后段不标空。

### A3. 核心新机制：冲突核驱动的成组支撑交换

令域节点值为 `x`；固定几何时，候选域值可写成 `a_rj^T x`。对每条有正确候选的射线选择一个临时责任 `y_r∈G_r`，求：

$$
\min_x \tfrac12\|x-x_{prior}\|_M^2+\lambda_b\|Lx\|^2
$$

约束为：

$$
a_{rj}^Tx\le-m_b\ (j\in\mathcal F_r),\qquad
a_{r,y_r}^Tx\ge m_b.
$$

`m_b` 是固定数值裕量，不是透明度；对域值尺度作统一规范，不能用任意 rescale 增加“置信”。`x_prior` 来自训练先验或统一初始化，不是最近一次错误输出的无限自确认。

**新步骤不是这个二次规划，而是责任配置如何变化：**

1. 保留“射线—候选—域节点”的稀疏关联超图。
2. QP 无解或高残差时，提取一个可复查的冲突子集；若求解器只给近似冲突，明确标为近似，不能当不可行证明。
3. 在冲突关联的射线与候选中，构造**联合责任交换**，允许多条射线同时换到不同候选。不能只给当前射线找一个后方正确面。
4. 用相同连续子问题评价联合交换。优先降低不可满足的可靠见证数，再优化几何/边界代价；不靠改变权重把违规隐藏。
5. 交换完成后，对全部 BUILD 射线真实回查：所有前段候选被排除、正确带仍有有效交点，才接受更新。合法交换可以改变原首面身份。
6. 出现 `G_r` 为空时，不凭域函数制造假命中；单独进入已有承载几何的构造性位移子步。A 不引入新基元列生成机制。位移后重建候选，重新执行共享域求解。

交换搜索可以用有界束搜索/局部离散优化实现，但搜索状态必须是**多条射线的责任配置及其共享约束**，不能退化为“score 高者胜”。第一版最多每次扩展 64 个责任配置、每对象 100 次外循环，数值预算在 FIT pilot 后一次冻结。

### A4. 伪代码

```text
输入：BUILD 观测 O；共享几何先验；只读标定和轨迹
初始化承载几何 V、域先验 x_prior、临时责任 y
repeat 至固定预算：
    C = intersect_all_untrimmed_carriers(V, BUILD_rays)
    F, G = split_by_observed_range(C)
    if 某些 G 为空：
        对现有承载片做有限构造性几何步；重算 C/F/G
    x, residual, conflict = solve_shared_domain_QP(F, G, y)
    if conflict 非空：
        Y = propose_joint_exchanges(conflict, ray_domain_hypergraph)
        逐个解同一 QP，保留真实违约更少/同违约下代价更低的配置
    导出同一 clipped mesh
    在全部 BUILD 射线上回查；接受或拒绝这一个候选资产

```

不允许以 `-logsumexp(b)` 代替硬存在判定。它有候选数量偏差和无界提高分数的问题。若内部使用软近似，真实接受条件仍以共享裁剪面求交为准。

### A5. 为什么可能有方法创新

研究增量是**可学习共享域中的析取支撑配置与冲突引导交换算法**，不是学习域、射线势、QP 或活动集各自的新发明。[R1–R6]

须证明的新知识：存在一类多射线共享约束，独立贪心或固定责任会卡住，但联合交换能够恢复可行域，而且该差异在真实稀疏表面恢复中有可测影响。

局部理论目标仅限：固定候选集合与可行子问题准确求解时，接受步骤不增加已列见证的违约；不保证全局最优，不保证从任意初始化有解，不保证未观测射线。

### A6. 最小证据实验

**机制组：** 构建四类固定几何案例，每类 20 个几何/射线实例。包括多个前面层、需要两条以上射线联合换面、候选为空、重复候选/域值缩放。训练只能读指定 BUILD；另保留查询射线检验过度裁剪。

小规模上用枚举或混合整数参考求解确定可行性及参考最优值，参考求解不读取留出真值。测试 A 是否真正解决联合交换，而不只是任何标准求解器都能解决的小问题。

**必要对照：**

- A0：完整域学习先例的正例—未标记思想 + 相同承载面 + 相同射线信息预算的常规软约束；不得伪称删减版为官方 Minimal Neural Atlas。
- A1：相同 QP、相同变量，只固定首面责任。
- A2：相同 QP、逐射线贪心更换责任。
- A3：标准增广拉格朗日/通用混合约束求解，在相同时间预算内运行。
- 小问题精确参考不算部署基线，不与大规模吞吐直接比较。

**真实组：** 公共约 48 对象队列，BUILD 求解、DEV_QUERY 判定。主比较为 A 对最强的 A0–A3；同时列原 r6/R8 与同预算逐资产优化控制。

### A7. A 专属晋级条件

1. 合成可行的联合交换案例成功率至少 90%，并相对逐射线贪心高至少 15 个百分点；无假可行声明。
2. 在标准求解器已可解决的案例上，质量不能明显更差；若唯一差异是速度，则至少达到 2×求解吞吐，且真实组仍满足共同质量门槛。
3. 在真实组满足第 8 节共同晋级条件；只保住 BUILD 而恶化留出覆盖，不通过。

**淘汰：** 通用求解器已解释全部收益；没有联合交换必要性；大量候选为空而只能靠迁移新表示救；域收缩使留出支撑明显丢失。A 不通过后，不改名再做“更强平滑＋再交换”。

### A8. A 埋点

`candidate_count / G_empty / F_count / responsibility_changes / conflict_size / joint_exchange_size / QP_primal_residual / rejected_exchange_reason / before-after first_owner / domain_area / retained_build_witness / heldout_support_delta`。

每次责任交换保留参与射线、相关域节点、候选距离和更新前后裁剪网格的最小可重放切片。失败不能只留下一个最终 loss。

## 5. 候选 B：射线区间约束有限元表面（RIF） ★★★

### B1. 唯一主假设

**对当前首面求梯度，天然看不到某些新交点与拓扑事件；若直接把观测编译成分片线性几何场上的整段无零点约束与返回零点约束，可以绕开“先有错面再修错面”的优化路径，并使场到网格的读出一致。**

B 不使用 A 的 chart 裁剪或责任交换，不使用 C 的基元库。其输出来自一个共享连续标量场的零水平集。该标量场的正负是内部几何表示，不作为未观测区的占据真值。

### B2. 表示

在对象规范坐标 ROI 内使用一致的四面体有限元网格 `T`，节点系数为 `c`：

$$
f_c(x)=\sum_{j\in tet(x)}\lambda_j(x)c_j,\qquad S(c)=\{x:f_c(x)=0\}.
$$

每个四面体内线性，跨共享面连续。零水平集通过同一线性插值提取，禁止另用 NeRF 期望深度或不同 SDF 阈值评价。[R7,R8]

局部几何编码器读取 BUILD 点、观测方向及只读尺度，输出场先验 `c_0`、正定度量/平滑权重和细分优先级。可以采用与 NKSR 类似的稀疏编码工具，但核心重建层不是复制其核求解器。[R9]

B 没有强制 genus-0 模板。计算域可以是固定的窄带四面体复形，边界不自动封盖；计算域由输入与共同几何先验确定，不能在发现违规后随意删单元。全 ROI 的零集也可能产生不必要闭合，必须在真实与合成测试中暴露，不能另加 confidence mask 救。

### B3. 从整条前段到有限约束：不是稀疏采样 free loss

一条射线与当前四面体划分的边界相交，得到前段的精确断点：

$$
t_0<t_1<\cdots<t_m\le t_r^*-\epsilon_{obs}.
$$

在任意相邻断点之间，`f_c(o+td)` 是一维仿射函数。因此若所有断点满足：

$$
f_c(o+t_jd)\ge\mu_f>0,
$$

该前段内部就不可能存在零点。它检查整个理想线段，而不是任意扩宽的射线管。新增四面体划分后重新计算断点。

在返回容差内引入一维潜变量：

$$
\tau_r\in[t_r^*-\epsilon_{obs},t_r^*+\epsilon_{obs}],\qquad
f_c(o+\tau_rd)=0.
$$

`tau` 只来自 BUILD 测量区间，不是测试距离。固定 `tau` 与网格后，该等式对 `c` 线性。以实际非退化等值面求交确认零点被导出；零场单元、切向接触、顶点退化不能当有效命中。

在允许的非切向局部，可加入一条有界的沿束下降约束来保证根不是零场退化；它只是局部几何条件，不把整个观测后段标为实体。硬条件不适用的测量必须留在失败/松弛统计中，不能排除困难评价束。

### B4. 新机制：返回根保留的自适应基函数重建

单纯“f(endpoint)=0 + 正值采样”不是主创新。B 必须实现三个绑定的步骤：

1. **射线断点编译**：对当前网格完整构造分段约束，避免自由段中遗漏零交叉。
2. **根约束保持的稀疏重建层**：先对固定网格/返回根解稀疏等式—不等式约束问题，再更新允许区间内的根。更新根后必须重解与回查，不把两步错位当保证。
3. **冲突/分辨率驱动的局部基函数细分**：只细分无法同时满足观察方向与返回根、或插值误差集中的单元；细分延拓保持当前连续场和已满足的根条件，再用新增自由度恢复不可满足观测。不能为了过拟合每条射线，在整场景无限细分。

固定网格子问题示意：

$$
\min_c \tfrac12\|c-c_0\|_M^2+\lambda\|Gc-g_0\|^2,
\quad H(\tau)c=0,\quad F(T)c\ge\mu_f.
$$

其中 `H` 是 BUILD 返回根插值行，`F` 是自由段断点插值行，`G` 是单元梯度算子。`M` 必须正定。局部求解已有成熟方法，不 claim 发明 QP。

测量不一致时另引入显式非负松弛，记录物理残差；有松弛时不能声称无侵入保证。返回根变化为非凸外层，不能将固定子问题的性质外推到全局。

**核心研究对象是“射线约束—有限元自适应—精确等值面导出”的同一重建层，而不是在 DMTet 上多加一项 loss。**

### B5. 能够追求的局部结论

在固定四面体划分、准确断点计算、无正松弛、非退化返回根和一致网格提取条件下：

> 前段所有断点的正值保证该理想射线前段无零集；返回区间存在被实际导出的零集交点。两者共同使该 BUILD 射线的硬首交点位于容差带内。

这是拟证明的有限离散表示结论，不是对真实传感器或所有未观测射线的认证。数学上用线性插值极值即可验证；论文价值取决于其与自适应重建算法的结合、性能与成本，而不在把线性函数性质重新命名。

### B6. 伪代码

```text
T, c0 = geometry_prior_and_initial_tetrahedra(BUILD)
tau = measured_build_ranges
repeat 至固定预算：
    H = interpolate_rows_at_return_roots(T, tau)
    F = exact_piecewise_ray_breakpoint_rows(T, BUILD_free_intervals)
    c, slack, active = constrained_field_solve(c0, H, F)
    mesh = extract_the_same_piecewise_linear_zero_set(T, c)
    validate_actual_mesh_on_all_BUILD_rays(mesh)
    若根/约束冲突来自局部表示不足且预算允许：
        conforming_refine_selected_cells()
        prolongate_field_and_rebuild_H_F()
    否则只在观测容差中更新 tau，并重新求解
输出：mesh、实际约束残差、网格复杂度、未满足测量
```

第一版禁止场边界负值填充以强行封闭、全体零值退化、未观测区统一正占据厚度标签和输出后任意去浮片。合成测试必须包含开口/薄表面，若 B 的表示不适合这些区域，如实体现为缺点，不从队列剔除。

### B7. 最小证据实验

**机制组：** 四类构型各 20 个：采样点之间隐藏零交叉；窄间隙与多个返回附近结构；粗网格根冲突需局部细分；带测距扰动与近切向观测。包含能被现有粗网格表示的案例与确实需要新增自由度的案例，不能只测自己占优的一类。

**必要对照：**

- B0：同网格/同先验的普通 endpoint + sampled free + surface loss。
- B1：同网格、同完整断点约束，但使用标准约束求解、不做射线驱动自适应；这是“强数学基线”，必须有。
- B2：相同最终节点/三角面预算的均匀细分或常规误差细分。
- 外部强方法：DMTet/FlexiCubes 或 NKSR 的可运行原生/同任务适配版本，公开每项输入与训练差异；不冒称所有基线单因素匹配。

**真实组：** 与 A 完全相同的 BUILD 和 DEV_QUERY；不得用留出深度把等值面钉住。

### B8. B 专属晋级条件

1. 精确算例不出现“断点约束声称满足、导出网格却提前命中”的未解释矛盾。
2. 相比 B0，真正减少采样遗漏的错误交叉，而非通过抹掉整个表面；相比 B1/B2，在同复杂度下有精度增量，或同质量下至少 2×求解/表示效率。
3. 真实组满足共同晋级条件。

**新颖性淘汰：** B1 已复现全部收益，所谓新重建层只是普通 QP 加线性约束；自适应不比相同预算常规细分好；无需新机制的现成隐式模型已实现相同结果。

**科学淘汰：** 只能拟合 BUILD，留出错误封闭面/过平滑显著；大量测量冲突需要宽松弛；网格提取仍改变根；单元数量不可控。失败后不补第二个裁剪场或大规模视觉分支来救 B。

### B9. B 埋点

`ray_cell_crossings / exact_breakpoint_count / sampled_vs_exact_violations / root_cell / root_shift / H_residual / F_min_margin / slack_by_ray / zero_tetra_count / grazing_cases / cells_refined / refinement_reason / prolongation_root_error / mesh_vs_field_first_hit / total_nodes_faces`。

每次细分保存父子单元及连续场延拓误差；事件失败至少保存一个能独立运行的射线—单元反例。

## 6. 候选 C：对偶需求驱动的表面合成（DCS） ★★★

### C1. 唯一主假设

**固定片集合没有正确支撑时，裁剪和首面梯度都受限；盲目增密又会制造新的提前面。由“哪些观测缺支撑、哪些自由段代价高”的全局需求驱动新几何生成，可以在固定最终容量下合成更有用的表面。**

C 从 BUILD 数据的稀疏种子出发，生成新的三维基元；不以删掉旧错误面作为唯一动作，不读取 r4/r7 的留出错误标签。它的核心是生成过程，不是 A 的域交换算法。

### C2. 表示与二维高斯的角色

最终表面是有限定向多边形片的集合：

$$
S=\bigcup_{j:z_j=1}D_j,\qquad
D_j=\{c_j+U_ju:u\in\mathcal P_j\}.
$$

`P_j` 为有限凸多边形，第一版使用 8 边形，可表达有方向、有限面积的局部表面。需要曲率时用多个片组合，不强制闭合。

可以借鉴 2DGS / LiDAR-RT 的中心、切向框架、尺度和高效求交表示，但：

- 不使用高斯无限尾部作为实体；
- 不学习 alpha、transmittance 或 ray-drop 来改变几何首交点；
- 实际存在范围就是导出的多边形，不是包围矩形代理；
- 选中的片全部按不透明几何求最近交点。[R12,R13]

**“换成 2DGS”不是 C 的贡献。贡献必须来自受全局观测需求驱动的新表面合成。**

### C3. 受约束的有限候选主问题

对候选片 `D_j` 与全部 BUILD 射线，预计算：

- `A_rj=1`：片与射线在正确距离带相交；
- `E_rj=1`：片与该射线的已声明可靠自由段相交。

第一版片为平面凸多边形，每射线每片至多一个非退化交点；若扩展到曲面，必须重新定义多交点关系。

受限主问题为：

$$
\min_{z,s}\ c^Tz+M_s\mathbf1^Ts,
\quad Az+s\ge\mathbf1,\quad Ez\le\nu,\quad p^Tz\le B,
$$

其中 `z_j∈{0,1}`，`p_j` 是导出面成本，`B` 是公共面预算。`s` 是显式未解释见证，不得在报告中消失。理想无噪声机制测试取 `nu=0,s=0`；真实冲突必须报告，不能宣称全部物理约束已满足。

`c_j` 是由局部几何、形状先验和复杂度产生的代价。不能由 DEV/FINAL 距离产生。训练时可用 FIT 的额外观测监督该代价对留出式 FIT 查询的实际几何增益。

最终是二值选择后的同一份表面，不是 LP 权重混合的透明表面。使用连续松弛提取需求后，必须重新求整数可行解或明确的离散可行修复；单纯阈值化 LP 不能当方法完成。

### C4. 核心新机制：需求定价的几何提议

主问题 LP 松弛产生三类对偶量：

- `alpha_r`：缺少第 r 条射线支撑的代价；
- `beta_r`：侵入第 r 条自由段的代价；
- `eta`：表面容量代价。

一个新片 `D` 的定价为：

$$
\bar c(D)=c(D)-\sum_r\alpha_rA_r(D)+\sum_r\beta_rE_r(D)+\eta p(D).
$$

这些变量是明确定义的约束乘子，不是额外猜测的“物理对偶占据场”。列生成和约化代价是已有优化工具，不 claim 发明它们。

**拟研究的增量：** 用这一全局需求构造局部几何提议器，让它输出此前字典中不存在的中心、法向和支撑范围；提议器读入高需求返回、局部输入点及高代价自由段，而不是只依据最近点密度或当前点误差增密。

实现路径：

1. 小型局部点/射线编码器读取同一个局部坐标框中的 BUILD 证据、`alpha/beta` 与已选表面摘要。
2. 输出若干完整有限片参数；候选数量有固定预算，不按结果无限增加。
3. 用真实多边形求交重新计算 `A/E`，核对实际约化代价，而不是信任网络预测。
4. 将负约化代价候选加入主问题，重新解整数表面选择；只接受实际共同目标/违约改善的结果。
5. 对极少量新片允许局部连续精修，但所有精修都重算全部相关 BUILD 交点。整数目标未改善的“LP 看起来很好”候选记为拒绝。

提议器训练可以使用 FIT 小问题的离线搜索候选作为排序/参数监督，另外使用 FIT 留出式查询评价候选增益；这些教师数据必须与其他方法的训练信息预算分开报告。最小证据先在小规模生成数据和原 FIT 子集训练，不要求大视觉模型。

### C5. 伪代码

```text
D = build-only sparse surface seeds
repeat 20 个固定定价轮次：
    A, E = hard_intersection_incidence(D, BUILD_rays)
    z_relaxed, alpha, beta, eta = solve_restricted_master_relaxation(A, E)
    proposals = learned_geometric_pricing(BUILD, D, alpha, beta, eta)
    exact_price = recast_and_price(proposals, all_BUILD_rays)
    D = D ∪ 合格的非重复新片
    z_binary = solve_discrete_master_with_fixed_face_budget(D)
    S = export_selected_opaque_polygons(D, z_binary)
    validate_full_BUILD_constraints(S)
输出：S、生成历史、未满足见证、LP与整数差距
```

这不是分片网络输出固定 1,536 个查询后再调半径，也不是根据验证错误删片。输出存在决策参与整个受约束重建，不允许删除对象条目。

### C6. 为什么可能有方法创新

PointTriNet 已有局部提议与分类；PolyFit 已有候选面选择。[R10,R11] C 必须超过“二者串联”：

> **利用全局射线约束的边际需求指导连续几何生成，并通过真正导出的离散表面回验生成价值。**

缺少正确候选时，新生成片能改变可行集合；已有某个正确候选但冲突很大时，提议器可以生成替代几何，而非只更换候选编号。

仅能声称对当前有限候选集/有限生成预算的近似求解。神经定价不保证找到所有负约化代价列；LP 改善不保证整数最优；不做全局最优或真实未观测几何认证。

### C7. 最小证据实验

**机制组：** 每类 20 个实例：初始字典无正确交点；正确候选存在但与其他观测冲突；密度很高但信息冗余；未知区域与薄结构。BUILD 与评价方向分离。

**必要对照：**

- C0：同初始字典 + 同离散主问题，无新增片。
- C1：普通最近残差/高误差区域生片 + 同主问题，提议数量相同。
- C2：PointTriNet 风格局部几何提议或可运行原模型的适配版本 + 同主问题；不能故意削弱其邻域建模。
- C3：相同提议网络，去掉 `alpha/beta/eta` 或打乱这些需求，但保留输入几何与训练预算。
- 合成小问题的扩大字典精确求解只作为参考，不计部署性能。

**真实组：** 同公共队列、相同输入与最终面预算。单看候选库增密后更接近 BUILD 不算成功，必须在 DEV_QUERY 上提升可复用表面。

### C8. C 专属晋级条件

1. “缺正确候选”构型中，在相同新增候选数下，有用支撑生成率相对最强普通生片控制提高至少 15 个百分点，并且实际硬首次命中同时改善。
2. 成功不能由最终三角面更多、片面积更大、教师信息更多或 LP 软响应解释。
3. 真实组满足共同晋级条件。

**新颖性淘汰：** 无对偶需求的同提议器已实现全部收益；普通误差增密 + 标准选择足够；所谓新机制实际上只是候选数扩大。

**科学淘汰：** 生成大量只记住 BUILD 的微小片、整数化后支撑消失、候选库爆炸、真实留出射线无收益。失败后不加透明度和传感器返回头救结果。

### C9. C 埋点

`alpha_beta_distribution / candidate_birth_reason / predicted_vs_exact_reduced_cost / new_correct_support / new_early_support / candidate_duplicate_rate / LP_integer_gap / accepted_column_count / price_failure / final_selected_area / primitive_count / build_vs_query_usefulness`。

保留生片前后真实表面及其影响的射线集合，区分“提议器没找到几何”“主问题选择错误”“整数化破坏可行性”三类失败。

## 7. 三个方法的独立性与比较边界

| 项目 | A / WEX | B / RIF | C / DCS |
|---|---|---|---|
| 基本变量 | 承载几何、共享 UV 域、临时支撑责任 | 四面体场系数、返回根、局部划分 | 有限片参数、候选库、离散选择 |
| 初始错误面处理 | 受约束地裁剪/移动并交换支撑 | 直接使同一零集满足区间与根条件 | 用更合适的新片替换候选组合 |
| 正确候选不存在 | 需要现有承载面的有限几何构造步 | 改变零集/细分可生成新的交叉 | 新片生成是核心能力 |
| 是否学习可裁剪域 | 是 | 否 | 第一版不学习连续裁剪域；选择完整有限片 |
| 是否依赖旧 V7.3 模型 | 不需要；可作初始化对照 | 不需要 | 不需要 |
| 最危险前序替代 | MNA + 射线势 + 标准约束求解 | DMTet/NKSR + 标准约束 + 普通细分 | PointTriNet/误差生片 + PolyFit 式选择 |
| 主要不可行风险 | 析取选择复杂、候选支持不足 | 场表示/根冲突、精度与网格量 | 定价不准、整数差距、字典爆炸 |

公共模块只包括数据读入、坐标、评价、BUILD 几何求交与记录。**第一轮不得把三个新机制组合使用。** 否则无法判断到底有几个独立有效方法。

## 8. 并行最小证据包与统一淘汰规则

### 8.1 一轮最小证据包，不是十几个阶段

每个候选只交付同一份包：

1. **机制算例**：第 4–6 节规定的可区分小问题、必要数值正确性检查及对应强控制。
2. **小规模真实重建**：同一预定队列，BUILD 离线求解，DEV_QUERY 评价。
3. **关键新机制移除对照**：删除“新”的部分，而保留相同输入、承载表示、优化预算和成熟组件。

只有第一项通过，仍不得宣布方法有效；只有第二项变好，但第三项显示新机制无增量，也不得晋级。

### 8.2 最小包的主评价范围

第一轮以选定的 **5 个 nuScenes 开发日志**为主筛选范围；3 个已曝光 AV2 日志为使用 AV2 自身 FIT 的单列开发切片，不混合为一个掩盖域差异的平均数。

两个数据集的先验训练互相独立，几何方法分别在各自 FIT 定标。nuScenes 仍是首轮筛选范围，AV2 单列自身域内验证；任一域失败保留且限定结论，不混合平均。先完成双数据集开发，再争取各自独立 FINAL；无法取得新的 nuScenes FINAL 时如实限制主张。

### 8.3 共同质量门槛

以下数值是本轮**预先设定的研究资源筛选标准**，不是传感器物理常数或已有实验结果。默认取值在第一次 DEV_QUERY 结果出现前冻结；只能根据 FIT 的单位/数值错误修正，不能看结果后放宽。

相对该候选最强的必要同合同对照，必须满足以下一条主改善路径：

- **支撑增长路径**：`hit ≥ +3.0pp`，同时 `early ≤ +0.5pp`、`free ≤ +0.005m`；
- **物理修复路径**：`early ≤ −3.0pp`，`hit ≥ −0.5pp`，且 `free` 减少至少 `max(0.01m, 对照free的10%)`。

两条路径都必须通过同样的支撑保护底线：

```text
miss 增加不超过 1.0pp
recall 下降不超过 1.0pp
any-correct-intersection 下降不超过 1.0pp
directed distance 增加不超过 0.01m
没有通过删除对象/透明化/输出空面/修改查询器达标
```

主改善方向至少在 4/5 个主开发日志一致。未定义指标不能当作达标；独立日志不足则记录真实数量和不足。

另外，对公共强参考（包括窄片 R8 及适当的现代重建方法）给出质量—覆盖—成本前沿。仅优于自家较差对照、但明显被公共强参考共同支配，不晋级。

**最小包用于筛选，不把小样本均值当最终统计证明。** 保留配对区间与每日志原值，但不要求此时所有指标都有很窄的 95% 区间。筛选通过后才在新独立日志验证实质增益和预定非劣界。区间跨零不等于保住了原表现。

### 8.4 共同新颖性门槛

下列任一情况成立，即使质量改善，也不晋级为论文主方法：

- 标准求解器 + 同信息/同表示已复现全部收益，新增步骤没有可辨识贡献。
- 对照只缺普通工程组件，补齐后差异消失。
- 收益只来自更大候选库、更多输入、额外逐资产时间、更多三角面或额外教师信息。
- 与查到的最近前序只有术语和应用数据不同，无法写出具体算法差异。

允许记录“有用工程改进”，但不能为凑三颗星把其继续保留在主创新竞争。

### 8.5 种子、预算与停止

统一用一个固定主种子完成最小包；初步通过后，用第二个预定种子确认方向。优化器确定性算法仍需检查训练先验/初始化敏感性。不跑一组种子再挑最好的。

每条方法第一轮建议预算上限：**5 个实际实现工作日 + 24 GPU 小时 + 96 CPU 核小时**，强外部基线的共同复现另计。它是初始资源分配，不是硬件研究上限。若当前实现明显需要更多资源，应在看 DEV 结果前一次说明并统一调整；不是看到负结果后无限续费。

所有方法使用同类 CPU/GPU 或报告设备差异；同时报告求解时间和最终精度，不把 CPU-heavy 方法隐藏在 GPU 小时之外。充分收敛有证据但成本较高，可以进入成本曲线；尚未收敛则不称假设被否定，但在本轮预算下不晋级。

**停止判定：**

- `PASS`：机制、真实收益、新颖性均达到预定要求。
- `FAIL_SCIENCE`：明确违背主假设或只能重演覆盖/物理取舍。
- `FAIL_NOVELTY`：标准方法足以解释收益。
- `FAIL_ENGINEERING`：实现/资源未在预算内形成有效证据，不宣称科学假设为假。
- `INCONCLUSIVE`：证据不足。本轮不自动晋级，也不按潜力延长试验。

`FAIL_*` 与 `INCONCLUSIVE` 均退出本轮竞争。工程错误可修，修复必须有具体反例；不能把算法本来需要的新机制称作 bug。每个候选至多一次有明确错误依据的更正复跑；不以此限制正常首次实现中的单元调试。

### 8.6 终止后不允许的补救

A 不通过，不加 C 的生片器；B 不通过，不加 A 的边界场；C 不通过，不加 learned transparency。不得因为剩一个方法就降低它的门槛。

只有原候选已经独立通过、且有明确互补证据时，组合才可作为后续独立扩展，并保留单方法主结果。组合不是本轮保底方案。

## 9. 并行执行方式

### 9.1 四个工作通道

| 通道 | 职责 | 允许修改 | 不应修改 |
|---|---|---|---|
| 公共评价/基线 | 数据角色、统一输出、评价、共同强基线、汇总 | 公共加载和评价接口 | 为某方法改评价语义 |
| A | 独立实现 WEX 与 A0–A3 | `v74/a_wex/` 及对应测试/日志 | B、C 实现 |
| B | 独立实现 RIF 与 B0–B2 | `v74/b_rif/` 及对应测试/日志 | A、C 实现 |
| C | 独立实现 DCS 与 C0–C3 | `v74/c_dcs/` 及对应测试/日志 | A、B 实现 |

公共队列、单位、数据角色与指标读出一次确定后并行。三个方法可以共用原始数据缓存，不能互相覆盖模型文件、共用可变求交缓存或争用同一个实验 ID。

每个工作通道对自己候选的主假设负责，不因别的通道先出分就修改候选。公共评价通道统一读取结果，避免各自选择有利分母。

### 9.2 推荐排期是交付顺序，不是成功承诺

- **起始 1–2 天**：建立公共数据/评价接口，补齐最危险前序与强控制，三个方法完成最小解析样例。
- **随后一个并行工作周期**：独立完成最小包；能早证伪就早停，不必花满预算。
- **一个统一裁决点**：给出三份结果和唯一的竞争决策，不滚动无限加候选。
- **胜者扩展期**：按实际复杂度预计另需 2–4 周进行充分训练、强外部基线和独立确认。这里只是计划量级，不宣称两周内必然形成论文。

共享模块异常导致三方法同样出错，应统一修复一次并重跑受影响部分，不能给每个方法都记一次科学失败。

## 10. 强基线配置：不让候选只战胜自家旧模型

### 10.1 必须保留的三层对照

**历史定位层：** V7.3 r6、r7、R8、LiDAR PCA。它们说明新增方法相对原进展的位置，不是所有方法的新颖性裁判。

**同机制强控制层：** A/B/C 各节中指定的同表示、同输入、同求解预算的标准算法。这层决定“是否真的新增方法”。

**外部竞争层：** 至少完成与最终胜者最接近的两类现代重建方法，以及一个强简单融合基线。候选名单为 Minimal Neural Atlas、NKSR、DMTet/FlexiCubes、PointTriNet、合适的 surfel/TSDF。按任务接口选择，不为了凑数量做六个弱移植。

外部方法若需要法向、密集表面或不同监督，分“原生可用输入协议”和“共同输入适配协议”报告。不从留出 GT 估计法向给基线或自家模型。AdaPoinTr 到面片的转换单列，不把转换伪面归因其原生点补全。

### 10.2 LiDAR-RT 应该怎么用

LiDAR-RT 是 2D Gaussian 与可微累积读出的传感器重仿真方法，不是直接以第一个代理三角形给出几何返回。[R13]

- 可以复现其原生渲染表，作为应用层参照。
- 若提取几何表面参与本任务，转换必须明确，原生结果与转换结果分列。
- 不能把其 alpha 去掉，再把这个削弱版本作为“LiDAR-RT”的全部成绩。
- 不能把“我们硬求交，他软累积”本身当优越性证明。

本轮不把完整 LiDAR-RT 传感器复现作为三个候选开始实验的阻塞项，但最终论文若选择重仿真 claim，则必须补直接竞争协议；不能继续只引用不比较。

## 11. 诊断埋点：用于解释一次失败，不用于制造无限诊断任务

### 11.1 每次重建必须保存的公共信息

```yaml
method_id: WEX | RIF | DCS
run_id: "v74_<method>_<cohort>_<budget>_<seed>"
phase: mechanism | mini_real | expanded | final
status: running | pass | fail_science | fail_novelty | fail_engineering | inconclusive
input_role: BUILD
query_role: DEV_QUERY | FINAL_QUERY
log_id: "真实ID"
actor_id: "真实ID"
input_counts: {owned_returns: 0, free_rays: 0, images: 0}
observation_protocol: "真实返回模式、时间近似、归属代理"
representation: "实际表示与容量"
initial_asset: "可复现初始化引用"
solver_budget: {iterations: 0, wall_seconds: 0, cpu_core_hours: 0, gpu_hours: 0}
metrics_build: {}
metrics_query: {}
constraint_residuals: {}
resources: {}
artifact_refs: {}
```

`metrics_query` 由评价通道写入，重建器不能读取它做实例内更新/停止选择。训练先验的 checkpoint 选择只能依据指定 FIT/开发协议；最终测试不得挑 checkpoint。

### 11.2 每条射线的必要状态

```text
ray_id / sensor_id / timestamp_or_time_approximation
origin / direction / observed_range_reference_role
initial_and_final_first_face / first_range / event_category
any_correct_support / early_with_later_correct
positive_witness_retained / free_violation
responsibility_or_root_or_column_id
```

BUILD 的测量允许进入求解；QUERY 的真值只在评价/失败回放产物中出现。诊断文件与求解缓存分离，避免后续意外把诊断标签作为模型输入。

### 11.3 保存失败过程的粒度

- 保存初始化、固定间隔的几何/表示状态、首次明显退化前后两个状态和最终状态。
- 保存每次关键事件的参数差分、接受/拒绝理由和最小受影响射线集合；不要求每一步保存完整大模型。
- 小规模方法状态可逐事件保存；大模型保留初始、指定中期、最后检查点与随机数状态，数据引用须能解析。
- 失败、未收敛、OOM、超时、空表面、无效根和未定义指标都保留，不只保留成功对象。
- 记录所有运行、所有固定种子，不能删除失败复跑或把最后一次成功当唯一历史。

### 11.4 失败可视化

每条候选预先固定三种展示选择：中位失败对象、最严重退化对象、改善对象各一个，并保留全部对象统计。图中只显示原始真实几何：责任面、BUILD 点、留出点、原射线及切平面。不平滑、不人工补面、不裁掉不利几何后当整体质量展示。

展示选出的失败切片不代表人口比例；比例从全队列算。相同对象的前后对照才可以称视觉消融。

### 11.5 常见失败归类

| 标签 | 含义 | 不能推导的结论 |
|---|---|---|
| `NO_SUPPORT` | 正确范围没有可用几何候选 | 不能归因于梯度权重太小 |
| `FRONT_POLLUTION` | 正确支撑后方存在，但前面错误截断 | 不自动证明必须删面 |
| `SHARED_CONFLICT` | 不同观测通过共同变量相互限制 | 不等于所有问题无可行解 |
| `SOLVER_GAP` | 标准/参考求解能满足，而候选求解失败 | 不等于表示不够 |
| `REPRESENTATION_GAP` | 在声明预算下无法表达必要结构 | 不否定该类表示的所有规模 |
| `BUILD_OVERFIT` | 构建约束好，留出表面/射线坏 | 不直接等于跨域根因 |
| `PRIOR_COLLISION` | 最近前序/简单控制解释全部收益 | 不意味着工程改进无价值 |
| `NUMERICAL_BUG` | 有解析反例或实现错误证据 | 修复后不算科学新进展 |

所有根因先写“观察”和“候选解释”，只有对应机制对照支持后才升级归因。每次失败最多追加一个真正能改变决策的针对性检查；不重建一整套取证工程。

## 13. 学习与求解怎样衔接，避免计划落地后变成另一个项目

第一轮不要求把离散交换、网格细分和整数选择全部做成端到端可微层。

- **A**：先采用固定或在 FIT 训练好的几何先验，检验新共享域求解算法。先验参数不根据某个 DEV 对象的留出质量更新。若后来学习初始化，必须给相同初始化下的算法对照。
- **B**：先检验固定先验场 + 约束重建/自适应层。需要学习 `c0/M` 时，只在 FIT 监督并保证 `M` 正定。可以在固定活动集下研究隐式求导，但这不是第一轮算法证据的必要条件，不能未经实现称端到端训练。
- **C**：局部几何提议器需要真实训练，不允许随机初始化提议器与成熟外部方法相比后直接否定路线。首轮使用小规模 FIT 教师候选/排序，代价监督来自 FIT 留出式测量，不来自 DEV。与 C1/C3 匹配训练样本、模型与候选预算。

三者的共同主张都是“从构建观测获得更好的可查询资产”，不是“共享表征已经跨域泛化”。若胜者后来加入视觉，在同一重建算法/预算下独立比较；视觉无增量时删除视觉主张，不影响已成立的 LiDAR 几何方法。

学习型列生成本身已有前序 [R14]，C 不得把“使用网络加速定价”单独列为原创。C 的方法增量仍必须是**连续三维表面生成与共享射线约束需求的对应关系**，并用同网络无需求输入的对照证明。

## 14. 胜者之后：如何形成论文，而不是停在最小正结果

### 14.1 只做必要扩展

胜者冻结核心机制后，完成：

- 更充分的 FIT 学习或离线收敛曲线；扩大公开数据中的对象和真实日志数量；
- 同信息条件下的强外部基线，完整质量—成本曲线与新机制消融；
- 新日志上的独立同分布确认，主任务命中/覆盖与自由空间联合评价；
- 固定背景与已知轨迹的场景组合，单列对象返回、边界代理和运动子集，不让背景主导的平均数遮掩失败。

这里不自动增加大视觉骨干、完整 LiDAR 微观物理或 RL。实时硬件求交仅在表面质量已成立后作为工程展示；不因接了 OptiX 就把论文改成完整仿真框架。

### 14.2 独立确认

首轮开始时就预留最终日志的身份清单，不查看模型质量。目标不少于 10 个新的、与 FIT/DEV 不重叠的 nuScenes 日志；具体数量按数据可获得性与先验功效估计决定，不虚构已经下载或足够独立。

最终只有一个胜者参与主要确认。用固定模型、固定逐资产 BUILD 求解规则、固定停止准则，不对 QUERY 调参。保存按日志配对区间和预定非劣界判断。

若同时对多个胜者作正式检验，明确其多重比较处理；优先避免这个问题，在开发阶段只选一个。旧 AV2 结果保留作为开发/压力证据；新的跨域 claim 必须使用新的确认日志。**单数据集的严格独立确认可以支持范围相符的论文，不把零样本跨数据集当普遍硬要求。**

### 14.3 不允许“确认之后继续拯救”

独立确认失败，保留真实结果，区分域内失效、跨域失效和证据不足。不得将该确认集改名为新 DEV 后，在 V7.4 中继续无穷重试；新假设需要新的版本/用户研究授权。

## 16. 自评与风险排序

### 16.1 当前立项判断

| 候选 | 方法级研究评级 | 最有辨识度的部分 | 最主要的淘汰风险 |
|---|---|---|---|
| A / WEX | ★★★ | 共享域的冲突核与成组支撑交换 | 标准混合约束求解已足够；无法解决缺支撑 |
| B / RIF | ★★★ | 整段射线约束、返回根和自适应零集的一致重建层 | 只是标准 QP + DMTet；场表示引入错误闭合/过平滑 |
| C / DCS | ★★★ | 对偶观测需求驱动连续新表面生成，整数资产回验 | 普通残差增密已足够；生成/整数选择脱节 |

**优先投入判断：A 最贴合既有证据，B 的局部数学合同最清楚，C 最直接面对“正确支撑不存在”。** 三者没有预设冠军。

这不是录用率或已确认原创性评分。提案写入时都没有实际运行，均无主任务新正结果；不存在可以如实声称的“已达顶会水准”。本轮承诺的是筛选质量：只给三个不同的核心候选，每个都规定能将自己淘汰的强对照。

### 16.2 为什么不加入第四、第五个候选

不加入“视觉一致性小头”“一般 ARAP/多尺度”“改名的因果场”“对数求和指数替代硬约束”“2DGS + OptiX”凑数。它们要么是成熟强基线，要么没有足够独立的新机制，要么重开已关闭方法族。

A/B/C 都可能失败。若三者失败，得到的是一个有边界的负研究结果，而不是继续再设计三个更复杂的名字。保留结果后停止，是本轮计划的组成部分。

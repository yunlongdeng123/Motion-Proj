## 1. 方向与判断边界

V7.3 主攻“冻结主体 + 可训练几何解码器 + 必要的局部参数高效微调（PEFT）”。不要求先穷尽冻结基座外挂路线，不按单卡 RTX 3090 限制模型或输入规模。

必须区分两个独立维度：训练方式中的路线 A/B（外挂/局部微调），不是之前任务选择中的路线 A/B（三维补全/激光雷达仿真）。选择局部微调，不意味着已经选择激光雷达仿真。

V7.2 的负结果只否定目前被实际测试的特征接口、候选支持与优化组合，不能否定视觉几何适配这一大类。静态源码显示，最终 CanonicalLateFusionEvidenceAdapter 的 surface_head 只读 physical_hidden；视觉特征只进入逐视角证据增量；该实现还将 blocking/detection logits 返回为零。其几何训练主要为 oracle 位移监督与零位移正则。因此它并不是一个已经充分训练的“视觉特征—几何—真实回波”联合解码器。旧版本已有尺度对齐，但主要是相机中心的最小二乘 Sim(3)，不是没有对齐，也不是充分的传感器约束鲁棒对齐。

V7.1 的关闭结论继续生效：不重开 primitive opacity 并集作为物理表面、不重做删除式安全、不救 M39 微调、不用 AV2 目标集调参。新设计必须增加实质的新可辨识信息、空间交互或生成支持，而不是改名复跑。

## 2. 主任务与唯一主假设

推荐起点：稀疏多模态观测约束的动态刚体 Actor 表面重建。

输入为构建时段的多相机图像、稀疏 LiDAR、标定、时间信息，以及已知 Actor 身份和刚体轨迹。输出为米制 Actor 规范坐标系内的可复用表面及其未知/支持信息。在留出时间和视点上评价表面恢复、自由空间侵入与字面首交点；把 Actor 放回固定背景后，评价场景级前景遮挡和射线深度。

初版聚焦刚体车辆。非刚体行人、关节运动、轨迹预测、强度、多回波、照片级渲染、强化学习均不是必须同时攻克的主任务。

主假设：当度量对齐、Actor 归属和时序对应正确时，对预训练几何解码通路进行有限适配，并让空间查询联合读取多视图和稀疏传感器证据，可以生成比逐点残差与普通深度微调更准确、更完整且更少侵入已观测自由空间的表面。

主假设不等于“更大的 Head 必然更好”“LoRA 必然泛化”或“高维特征必然过拟合”。

任务调整只有一个必要出口：如果经过公平几何适配后，稳定增量仍只出现在真实回波存在性/距离分布，而不在表面上，且原生束协议与完整背景可用，再正式切到神经激光雷达仿真。不能仅凭 F/O/U Brier 选择这个出口。

## 3. 推荐架构

![V7.3实际组件与数据流](../paper_v73/figures/architecture_components.png)

图示为当前已实现原型；新的表面参数化尚未选定，不把未来模块画成已有结果。

图像 -> 冻结视觉编码前缀 -> 原生多层几何特征与可训练解码部分；
LiDAR/标定/轨迹 -> 米制对齐、规范坐标、多尺度传感器邻域；
两路证据 -> Actor 局部空间查询解码器 -> 稠密表面支持与局部连通信息；
表面 + 只读刚体轨迹 + 背景 -> 统一表面查询与首交点评价。

### 3.1 基座与可训练范围

优先使用现有已可运行的 VGGT，但不把 VGGT 写成永不可替换的依赖。VGGT 官方已经提供冻结 aggregator、微调任务头的训练示例；原生 DPT 解码头读取多个中间层，而非只有最后一层均值特征。先利用已有预训练几何解码能力，不无理由把它全部替换成随机小网络。

默认训练新的局部查询解码器及必要的原生几何解码部分。确有跨视图对应瓶颈时，在聚合器的上层注意力投影增加 LoRA。早期视觉编码和多数主体参数保持冻结。卷积型 DPT 层可以直接局部训练或使用匹配算子的低秩更新，不把所有模块都误当成具有 q/k/v 的注意力层。

设置一个保守比较候选：只微调原生深度/点图解码器或有限 LoRA，使用常规几何损失，再做统一规范坐标融合。这是要被认真训练的强基线，不是故意弱化的两步试跑。

“训练新查询解码器”与“必须改变预训练参数”不是同义词。可以冻结原参数训练新解码器，也可以加入 LoRA；两者的增量要分开验证。

### 3.2 坐标、尺度和时序必须先有物理含义

规范坐标定义为 x_i = T_i(t)^(-1) x_world；每条观测使用自己的采集时刻。相机中轴向深度 z 与 LiDAR 沿束距离 d 不能直接混用。图像裁剪、缩放要同步更新投影关系。网络可以使用归一化坐标，但所有物理损失与最终评价恢复为米制；非等比例框归一化后的法向也需正确变换。

优先用 build 侧静态/可靠对应与已知相机标定进行米制尺度对齐。必要时用 Huber/IRLS 估计少量尺度或刚体偏差；多相机、跨时间共享约束比每帧任意漂移更重要。对没有真实尺度自由度的米制模型，不强加任意 scale/shift；不让网络通过改变标定和 Actor 轨迹抵消错误几何。

TALO 可提供“先处理全局尺度，再处理空间变化残差”的启发，但其 TPS 非刚性对齐不能直接等同于刚体 Actor 的物理先验。

### 3.3 从逐点回归改为联合空间查询

每个 Actor 保留一组带三维位置、局部尺度、来源信息和隐状态的查询。查询可由 build LiDAR、对齐后的图像点图与可学习粗查询共同初始化。新增查询必须可以在旧 candidate 支持之外生成表面，不能继续锁死为旧点的小位移或固定子点复制。

每轮查询更新包含：同一 Actor 的局部多尺度查询交互；在对应时刻投影到各相机的局部特征读取；与 LiDAR 邻域/自由空间证据交互；几何位置与局部表面参数更新。

投影使用 T_camera_from_world(t) T_actor_to_world(t) x_query。对动态 Actor 不能把不同时刻的像素直接当成静态对应。允许在位置不确定范围内做局部可变形搜索；不做全图高维 token 无条件平均。

不同 Actor 独立建立规范形状记忆；背景通过独立分支或固定几何处理。场景级遮挡由世界坐标下的射线顺序组合，不用同一个全局形状向量混合所有运动体。

高维 token 不等于纯语义噪声。优先比较原生几何解码中间特征、少量分层特征及可学习瓶颈；语义只作辅助，几何坐标、观测方向、深度残差与支持量是显式输入。是否压缩、压缩到何种容量，由训练/开发差距判断。

### 3.4 输出表面，而不是新的任意 opacity 集合

起点可用粗到细点集/局部曲面片解码：先生成覆盖整体的查询中心，再预测局部表面点、法向和可用于统一显式化的连接关系。AdaPoinTr 的自适应查询和集合生成可作为实现参考，不要求从零发明所有组件。

生成器与后续表面转换要分开评价。点图/点集结果通过统一转换得到可查询表面；如采用局部网格，应避免跨遮挡边界和空间不连续区域连边。不能把纯点集膨胀成凸包后，将凸包造成的假回波归因于基础模型。

不再让球/椭球/圆盘的独立 opacity 并集定义物理几何。置信度可以描述未知性，但不能让错误表面通过低置信权重从几何指标中消失。

### 3.5 修正状态所有权

图像观测及其几何相关特征可以在构建时影响物理表面。应隔离的是外观状态的修改权限与外观渲染损失的梯度，而不是禁止物理重建读取任何图像。

构建后，外观颜色/球谐系数/透明度不改变已冻结物理表面；Actor 轨迹只通过刚体变换作用于表面。运行时不依赖当前查询重新生成一个不同形状。

## 4. 数学物理先验的使用位置

整体运动使用已知 SE(3)，不由形状网络重新解释运动。车辆刚体假设成立时，先解规范形状，再组合轨迹；不把四维动态复杂度全部交给局部 Head。

局部结构可选近似刚性（ARAP）、边长/法向一致性或轻量控制图，抑制撕裂、局部拉伸与查询塌缩。ARAP 的参考应来自可信粗结构，不能强制保留已知错误的初始几何。只在有意义的局部邻接内正则，避免跨车窗、薄结构和遮挡边界抹平。

样条是可选的低频残差参数化，不是默认主模块。样条平滑不等于刚性；弯曲能不自动限制缩放、剪切、折叠或自交。需要局部刚性时，应显式约束对应的局部变换。平滑可逆形变也不能创造缺失的拓扑或表面支持，支持生成仍由查询解码承担。

优先级是米制对齐、真实空间交互、支持生成、直接观测监督；有诊断依据后再添加 ARAP 或样条。不要因为数学形式优雅就全部叠加。

## 5. 损失设计：四类语义，不是尽量增加项目

建议以 L = L_data + λ_event L_event + λ_free L_free + λ_struct L_struct 为组织方式。多尺度监督属于这些项的实现，不另造很多独立贡献。

### 5.1 坐标与表面数据项

L_data 直接约束米制几何，不仅回归旧 oracle 位移。可靠对应处使用点到点/点到平面的鲁棒残差；多尺度下约束覆盖和位置；点集监督可借用局部软匹配，并逐步缩小匹配范围。

法向来源不可靠时，不强上点到平面。稀疏 target 只代表被观测表面，不代表物体完整真值。预测到 target 的惩罚必须区分已评价可见区域、明确自由空间与未观测区域；不能把未采到点的未知表面全部惩罚为错误。软最小匹配应控制候选数量带来的偏置，不能让更密的点集仅因 log-sum-exp 项数增加而获得更低损失。

可靠性权重应来自测量或有约束的估计，不能让网络通过把难样本置信度降到零逃避监督。鲁棒核用于脏对应和测量离群；不能无差别截断真正危险的前向侵入误差。

### 5.2 首事件似然

对按深度排列的候选区间，令 u_k 表示条件终止概率，则
p_k = u_k ∏_{l<k}(1-u_l)，
log p_k = log u_k + Σ_{l<k} log(1-u_l)。

对有效观测距离 d*，可使用
L_event = -log Σ_k p_k N(d*; d_k, σ^2)。

用 log-sum-exp 和稳定 logit 公式计算，而不是连乘后再加大 epsilon。理想已知命中区间下，错误前景 logit 的梯度为 u_l，真实命中 logit 的梯度为 u_k*-1；这说明对数似然可避免某些由乘积透射率引起的数值/梯度问题。

边界：上述结论针对明确支持和固定顺序下的 logit 梯度；不自动解决缺失候选、错位对应、表面位置梯度、遮挡切换与硬读出的全部问题。u_k 应与生成表面的几何关系关联，不能成为可随意把错误早表面“变透明”的独立逃逸通道。区间概率与离散分辨率要一致；不能因为重复一个支持点就增加一次独立命中机会。

训练期间可以用 target 定义监督窗口，但推理射线的搜索范围、候选和位置不能读取 target depth。没有命中支持时，要补查询覆盖或提供几何梯度，不只修改 softmax 温度。

首交点几何与首个被检出的传感器返回不是在所有材料/传感器下等价。未建模透射、多径或漏检时，应明确单有效首表面的适用近似。完整仿真中的 blocking/detection/no-return 是额外传感器问题；不能从仅有返回点的文件推定无返回标签。

### 5.3 自由空间项

对有效首回波之前的已观测束段，直接约束所生成的几何不得侵入。损失不能只乘预测 opacity/置信度，也不能只作用于平均深度。只对射线管内、可归属且几何相交的局部表面建立约束，不把所有空间上无关的点都沿某条 ray 推走。

必须使用原始首回波和全场景遮挡归属：一个 Actor 被前景遮挡时，不能把后方 Actor 的 target 深度当成原始束的首返回。

可以比较普通铰链与局部平滑版本。材料中的 C² 铰链为，t=x/δ：
Hδ(x)=0 (x≤0)；δ(t³−t⁴/2) (0<x<δ)；x−δ/2 (x≥δ)。

它在满足约束一侧严格为零，连接处二阶连续；违规远侧恢复的是原铰链的梯度，函数值相差常数 δ/2，而不是逐值完全相同。它是优化选项，不是独立论文主贡献。

### 5.4 局部结构项

L_struct 用于局部面片连贯、法向/边长合理性、避免查询塌缩与不必要的变形。只选择当前失败模式要求的少数约束；避免重现“零位移先验很强，所有几何更新最终归零”的局面。

## 6. 平滑性材料的采纳与保留意见

采纳：区分连续、非光滑和离散可见性切换；对几何匹配使用局部软到硬延拓；首事件监督优先于只监督期望深度；拒绝人为给不透明表面添加固定透射率泄漏。

温度/窗口/核宽从较宽逐步收紧，但收紧终点不应低于合理的传感器、时间与位姿误差尺度；也不能通过让可学习噪声无限变大来掩盖错误。温度调整应随匹配和硬指标的稳定情况变化，而不是机械按 epoch 把所有项同时变硬。

硬前向不变、另设一个软损失，并不自动得到硬渲染器的正确梯度。边界采样和重参数化渲染的理论有专门条件；不把直通估计或任意软反传包装成无偏/精确梯度。

首事件生存结构、深度终止分布监督都已有工作，DS-NeRF 和神经激光雷达领域是必须对照的先例。将其换为损失不能直接声明新物理模型或已消除代理鸿沟。

IRLS/GNC 的现有收敛结论依赖具体目标、数据条件与子问题解法；不能移植为深网加 AdamW 的全局/二次收敛保证。

材料中的 38.03% 代理反转、86%–90% 梯度冲突是转述，不是本轮重新确认的 V7.3 统计量；可作待查线索，不直接写入新稿。

## 7. 灵活实验路线

### 第一轮：给几何一个真正可学习的强起点

在真实多日志上认真训练原生几何解码器/有限 LoRA 基线，与鲁棒对齐及简单融合比较。观察损失是否能改善真实坐标和可见表面，而不只是旧位移标签。同步建立支持覆盖，不重复只挑每日志极少数没有目标可见性的窗口。

如果直接微调已有明显收益，说明旧表示/训练通路是瓶颈，再加空间查询检验额外增量。如果直接微调训练集都拟合不了，优先查对齐、梯度通路、生成支持和监督定义，而不是立即换几十个 loss。

### 第二轮：空间查询与局部适配的增量

固定主任务和数据，比较逐点解码与局部查询解码，并区分是否微调预训练几何部分。较大逐点 MLP 可作为一次容量控制；不能仅凭参数更多宣称空间结构有效。

第一主候选是“查询几何解码 + 有限适配”；必要保守候选是“原生解码微调 + 统一规范融合”。不用同时维护多个完全不同的世界表示。

### 第三轮：几何—首事件一致性

在同一个已经能学习几何的模型上，比较常规几何/深度目标、加入首事件与直接自由空间监督、再加入确有必要的延拓优化。这样能区分收益来自损失语义还是平滑，避免把架构、监督、优化一起修改后无法归因。

若期望深度改善但字面首交点变差，检查表示/读出耦合；不能靠继续降低温度或选择中位数宣布解决。梯度冲突持续时，先看数据和损失尺度；PCGrad/CAGrad 仅作必要诊断或比较，不默认叠加。

### 第四轮：独立确认与应用

将胜出的紧凑方法应用到新日志、匹配输入预算的强基线与场景级前景遮挡任务。先稳定一个基座，再决定第二基座是否值得扩展；第二基座单独训练适配器与同一个适配器直接迁移要分别表述。

所有结构、超参数和方向选择使用开发数据。若旧 source 被用来决定新窗口/结构，它就不再承担全新最终确认。纯工程错误可以修，不需要因旧报告格式或哈希冻结而永久卡住研究。

## 8. 失败诊断到下一动作

- 训练集也不能恢复几何：检查支持范围、坐标和真实梯度路径；再扩大解码容量或局部解冻范围。
- 训练改善但跨日志退化：增加独立训练日志/有效观测覆盖，检查对应污染，再比较更小的适配范围、几何特征瓶颈与正则。
- 几何更准但早交点增加：检查表面显式化、遮挡归属和自由空间约束，不把它归为“分段损失必然失败”。
- 几何损失下降但表面不动：检查零位移先验是否压制更新、旧 oracle 标签是否限制动作空间。
- 完整模型只比弱 scalar 好：转向当前最强同信息基线比较，不继续包装四项机制支持。
- 只有回波校准提高：降低重建贡献主张；只有真实传感器主任务也提高时才考虑仿真出口。

改变方案时说明修改的结构假设与预期改善的指标。允许尝试，但不以次数和模型名称计进度。

## 9. 基线和证据

必须保持同一 build 帧数、LiDAR 点/束预算、相机覆盖、标定、轨迹信息和输出评价算子。预训练数据与是否逐场景优化单独披露。

建议基线层次：
1. LiDAR 累积、surfel/TSDF 或适用的简单融合，以及基座 + 鲁棒米制对齐。
2. 原生解码器微调 / 普通 LoRA + 常规几何损失。
3. CAPA 类稀疏深度驱动适配：它是最近的路线竞争者之一，需与本任务兼容后比较，不冒称其原生就完成动态 Actor 补全。
4. AdaPoinTr 的认真训练版本，作为集合补全竞争者；LDCM 可作为较强二维深度补全后规范融合参照。
5. LiDAR-only + 同一解码器、图像/几何先验 + 简单融合，识别多模态信息各自贡献。

三维重建为主任务时，DyNFL/LiDAR4D/LiDAR-RT 是相关应用或适当协议下的比较；若主任务切为完整神经 LiDAR 仿真，它们才变成必须正面竞争的核心基线。不能拿它们与局部点集在不同预算/不同算子下强行排名。

CAPA 等逐场景优化方法与共享训练模型分栏，报告训练摊销、每场景适配时间与全链路推理成本。允许后续 build-only 适配，但不读评测 target，不把做过本场景优化称为零样本直接迁移。

## 10. 数据与评价最小要求

优先复用已经可合法访问的公开数据，不把下载、校验等当论文贡献。nuScenes 可作为已有入口；完整 no-return 任务则需可靠原生束协议后再启动。无需同时承诺大规模 Waymo 取数与几何原型。

视觉支持资格由 build 输入和元数据决定；不按模型置信度过滤最终人群。对缺视觉但有 LiDAR 的 Actor 保留 LiDAR 路径，并报告其比例和性能。可观测性/覆盖不足是系统适用性证据，不能只写“无法计算”然后在主结论中忽略它。

最终评价按独立日志聚合，报告配对差值、不确定区间、有效覆盖和关键尾部切片；大量射线不能充当大量独立样本。尽力积累数十个独立日志，规模由实际可获取数据和统计精度决定，不硬写一次性门槛。

表面指标：在明确可评价域内报告 precision/recall/F-score、Chamfer 与密度影响；自由空间与回波指标：侵入比例/幅度、字面 early/hit、有效回波误差及预测缺失率。不能只删除不返回的射线再统计深度均值。

局部补全结果放回同一固定背景，所有方案使用相同 Actor 位姿及组合规则，评估新视点下的前景/背景遮挡。反事实轨迹可展示组合与查询能力；没有真实反事实真值时，不把编辑结果宣称为传感器真实性验证。

## 11. 算力、实现与文稿

计算配置由视图数、图像分辨率、空间查询规模和适配层深度决定。可以使用大显存 GPU、多卡数据并行或必要的参数分片；不为适配 24GB 先砍掉关键空间/时间信息。PEFT 降低可训练参数和优化器状态，不消除激活显存与反传计算。

只有完全冻结的计算前缀可缓存为不变特征。对存在 LoRA 的层，每次训练必须经过它；不能读取旧最终缓存却声称训练了该通路。普通 dtype、数据加载和空支持错误直接修，避免不必要的全套回归流程。

保留规范化、标定与数据适配、构建/目标隔离、统一硬评价器和状态所有权。新研究核心尽量只包含数据、模型、训练、评价与结果整理，不继续导入大量历史 M 入口作为方法。

从开始同步维护 V7.3 LaTeX 的任务、方法假设和当前证据表。先回答一个可复现的主结果，不能用渲染桥接、SE(3) 恒等式与合成解析机制替代它。论文主张不预写“首次”“帕累托最优”“稳中”或安全保证。

## 13. 四项风险的实质修订（revision 2）

统一失败/风险账本引用：`V73-F01`–`V73-F04`；继承 `V71-F20/F22/F54/F66/F68/F69`。这些是待实验判别的风险，不能预写为已解决或方法负结果。

### 13.1 先投影、再局部采样，保留完整时空输入

使用已知时间对应的 `T_camera_from_world(t_v) T_world_from_actor(t_v) x_actor`，在投影位置读取 L 层、每层 K 个局部采样。保留相机/时刻、相对方向、尺度、像素偏移和可见性信息，再进行局部交互。采用 Deformable DETR 的参考位置和多尺度稀疏采样思想；不把其二维检测效果直接当作三维重建证据。

查询与图像交互规模由 `O(Q V H' W')` 变为 `O(Q V L K)`（不含特征维与反传常数），默认不用全图 dense cross-attention。Actor 内采用局部邻接；消息传递为 `O(Q k)`，但普通全量 `cdist` 构造 kNN 仍为 `O(Q²)`。实现应使用空间索引/体素邻域或分块距离，并分别报告建图与交互成本，不能把建图成本隐去。

查询分块、视图累积、混合精度与 checkpointing 是执行优化；不能为 24GB 静默减少时刻、相机或输入分辨率。仅冻结前缀可缓存：完整冻结 aggregator 后的多层 token 可以用于**原生 DPT 真正反传**；训练上层 LoRA 时必须重新执行对应层。不能以旧最终 feature grid 训练一个小头冒充适配原生通路。

先用当前原生 DPT 做真实更新并记录峰值显存/容器内存/每步时间；若优化执行方式后目标配置仍不足，再申请大显存卡/分片。当前机器实际 cgroup 内存为 **90 GiB、CPU 配额 14 核**，不能将宿主 `/proc/meminfo` 的约 755 GiB 当可用额。普通 DDP 增加总吞吐，不减少单样本激活，应区别于参数/激活分片。

### 13.2 生成支持同时承担覆盖与自由空间责任

查询以 evidence-anchored 与 completion 两种来源初始化，共享解码器；这不是两个独立模型。使用观测 target 到生成表面的 coverage 项保持已观测表面召回；`UNKNOWN` 保持未知，仅原始有效首回波之前的已观测射线管提供 free 标签。

自由空间项直接作用于表面位置/相交关系，不乘可学习 existence、confidence 或 opacity；不允许关闭查询或把半径缩到零来逃避惩罚。初版固定或由传感器分辨率决定读出支持尺度，保持所有候选同算子。若以后学习曲面支持范围，必须同时承担面积/覆盖责任，并报告塌缩；不能只比较条件命中误差。

对长期覆盖/free 冲突，优先定位错时、Actor 归属、原始束遮挡、米制尺度或显式化半径，不先扫损失权重。未知区域的预测不因缺 target 被罚为空；评价表中同时报告可评价域、覆盖、侵入和 missing fraction。

### 13.3 首事件是观测顺序修正，几何监督负责 support birth

固定候选上的对数域 event 梯度结论不保证缺支持时的位置梯度。模型应持续得到直接 surface/coverage 吸引，不在没有命中候选时仅优化 NLL，也不把这类射线从分母删除。

训练先以几何恢复为主，之后逐步提高 event 权重，同时保留 coverage 和已观测 free 约束。需要时采用归一化局部软匹配和有限宽度延拓；宽核只能扩大已有候选吸引域，无法为硬剔除的候选创造梯度。缺支持射线必须仍得到三维最近支持吸引或 coarse-to-fine 细化的训练信号。噪声宽度固定于合理传感器/位姿容差，不可无限增大。

训练 target 可用于 loss，**不能作为推理查询初始化或候选出生位置**。推理时任何自适应细化仅依据 build LiDAR、build RGB、已有查询和已知位姿；最终 held-out target 不进入 refinement。这也是与 AdaPoinTr 去噪/补全查询迁移时必须保留的训练/推理边界。

event 概率来自同一表面的几何关系与深度区间，重复一点不能创造一次独立终止机会；不得用任意 opacity 令错误前表面透明。DS-NeRF 已监督终止分布，本项目不将替换 NLL 本身列为创新。最小辨别比较为：同架构几何监督、加 event/free、必要时加延拓；同时记录支持缺失比例和字面硬交点。

### 13.4 所有权保留到场景级硬读出

静态表面与各 Actor 规范表面独立保存，组合为 `S_static ∪ (∪_i T_i(t) S_i)`。静态构建时用每个观测时刻的动态归属排除 Actor 测量；只在最终位置裁掉背景不能清除历史轨迹 ghost。Actor 后方未见背景保持 UNKNOWN。

射线先对各所有权层求几何交点，再在场景级统一深度排序，得到字面首交点及 owner。不能以外观 alpha blending、Actor-only target 深度或背景自动补洞代替物理首回波。重叠模糊归属单独报告，不同时把同一测量写进背景与 Actor。

车辆尺寸仅用含 margin 的软 envelope；不以硬 box 截断制造漂亮边界。场景比较使用相同背景、轨迹和算子，分列 Actor 本体、背景 ghost、边界带和背景缺失；没有反事实真值的编辑只作组合展示。迁移 Street Gaussians 的 Actor/背景分解，不迁移其外观 opacity 作为物理读出。

## 14. 原生支持的恢复梯度（revision 3）

共享训练r1初始25/25 Actor有原生深度候选，epoch3的20次fit更新中16次因native预测没有框内候选而回退LiDAR。参见V73-F06与当前台账；这是训练中的实测风险，不是对所有PEFT方法的结论。

预测支持选择、几何适配和自由空间目标不能形成自我关闭通道：归属框和fallback用于正确组织观测，但不能成为原生解码器唯一的几何梯度入口。保留从build侧已知Actor的传感器测量，按正确时刻/标定直接监督原生深度或点图的路径。即使当前没有预测支持落在Actor域内，原生输出仍能收到返回物理表面的梯度。此项并非对冻结输出的蒸馏，也不限制有效几何修复。

先以当前build点的米制轴向Huber作为与coverage/free同训的控制实验，其目标是区分支持逃避与真实表面改善。后续event只处理终止分布和观测顺序，不能取代上述缺失支持恢复路径；置信度和推理fallback不得屏蔽几何评价。空候选和重复种子数量须作为支持事实报告，不当成独立观测量。

## 15. 三角比较后的表面参数化决策（revision 4）

用户明确保留可训练几何基座、显式三维表面生成和物理约束这条主线。原生DPT融合是认真训练的强控制与问题定位工具，不因当前Query候选的负结果自动成为最终路线。既有V73-F02记录覆盖与free冲突，F03记录缺支持的event梯度边界，F04记录场景读出/背景差异，F09记录完整原生适配的开发hit退化；这些现象都不能单独否定几何基座适配。

### 16.1 Near-surface certified-free boundary loss：有条件可行

[ViGT论文第3.3节、表3与附录A](https://arxiv.org/html/2602.05573v1)在分层采样外增加返回前的近边界负样本；其占据场实验支持这种采样分配。论文使用0.1m厚度，并在返回后定义正占据区间。[作者仓库](https://github.com/whesense/ViGT)标注IJCAI2026录用；本次公开树可见模型、渲染与示例，未找到训练采样器，不声称已核对其训练实现。迁移的是边界监督密度的思路，显式Actor曲面上的收益仍待检验，不复制正体积厚度或occupancy渲染。

对原始首返回距离 `d*`，新增负采样只能位于可靠的返回前区间，例如 `s ∈ [max(0,d*−b), d*−m]`，其中 `b>m`，m反映既定测量/时刻容差。当前m为0.20m：照搬ViGT的0.10m近边界宽度会得到空的可靠区间，不能为迁移而静默缩小容差。b依据现有误差与待修正表面范围确定，不预设为贡献或发起权重网格搜索。

认证来源必须是原始有效首回波与正确归属/时刻；后方Actor不能把自己的表面当该束首返回。首返回后、射线间未观测区域与遮挡未知区域均不新增FREE标签。源码 `motion_proj/worldsim_v73/surface_visibility.py` 中0.03m宽、有限3σ的footprint明确是训练代理，不能称为实测光束或严格认证体积。新增项先沿有测量依据的中心束前段定义；若扩到三维邻域，须有传感器足迹或可靠多束证据支持。不能以任意半径自由球把周边未知空间一起清空。

关键实现问题是梯度落到同一显式表面：当前finite-beam range已经在可见三角面内部通过插值距离提供位置梯度，增加沿深度采样数量不自动产生新信息。显式三角面也没有可直接套BCE的occupied logit。优先考察近边界分段内的实际相交表面约束，能否让被更早错误片遮住的违规片也收到位置梯度；这是候选设计，不是已证实收益。保持每条原束/固定区间的归一化，不让复制片、加密采样或同一面被重复计数改变罚则强度。若用点到三角面距离形成排斥势，作用域必须限于可认证自由域，不能把未知近邻也解释为空。

该项补充全射线/finite-beam L_free，并持续保留测量target→surface的coverage吸引。只在已有相交支持上生效的损失仍有离散支持边界，不能声称解除F03的support-birth死锁；要把“新增违规片的位置梯度”和“无支持处能否生成表面”分开回答。约束最终所有生成表面，按completion/evidence来源分析效果，不给任何来源免罚，也不用confidence、opacity、删除查询或缩到零的支持范围逃避。

### 16.2 Calibration-guided local cross-attention：补一致性，而非重复已有模块

当前 `motion_proj/worldsim_v73/spatial_queries.py::ProjectedLocalRead` 已按只读标定与Actor在曝光时刻的刚体变换投影，读取4层×4个邻域位置并做Q/K cross-attention。`offsets` 是可训练线性层，圆形仅为bias初始化；前向为 `tanh(offsets(h))*4`，每层的两个坐标分量分别限定在±4个特征像素内。现有几何嵌入已含中心camera ray direction、query轴向深度、时刻、投影uv、相机和尺度身份；因此“固定offset→加入attention/方向”不是当前代码的实际新增量。

真正缺少的是候选像素上的predicted-depth残差、偏移后的射线几何以及有观测依据的遮挡/Actor归属一致性。当前所谓visibility仅表示相机前方、图像与有效裁剪范围内，不是遮挡可见性。可行接入点是在既有局部候选key/value或attention bias中加入这些证据，精确投影仍决定搜索中心，attention只修正有界局部对应；不学习修改标定、尺度或轨迹来吸收几何错误。

深度比较统一为候选像素的米制DPT轴向z与query相机z，不能混用LiDAR沿束距离；候选射线方向按偏移后像素与同一K恢复。可靠build点可提供局部最近z/归属证据，但投影框内像素不自动属于Actor，未测像素也不是背景真值。错误DPT深度不能通过硬mask切断所有视觉/几何梯度；预测深度只作有界软一致性证据，并保留原生build深度直接监督和缺视觉fallback。若一致性支路能通过移动自己的深度消除残差，优先考虑对用于打分的深度cue停止梯度、保留DPT几何/特征主梯度；此取舍需在实施时明确，不能宣称已阻止自我关闭。

attention权重不定义物理可见性真值，更不能屏蔽最终表面的L_free/event或硬首交点评价。保留query_chunk=128与稀疏 `O(QVLK)` 读取，不展开全图attention，不为此减少原有24视图。

[GNT作者项目与代码](https://vita-group.github.io/GNT/)提供几何对齐的多视图attention参考，但其神经渲染和注意力可解释性不是Actor物理可见性保证；[TransFusion论文及作者代码链接](https://arxiv.org/abs/2203.11496)支持标定关系附近软关联的动机，其3D检测成绩不等于表面重建收益。这里迁移局部对应组织，保持当前几何/物理读出语义。

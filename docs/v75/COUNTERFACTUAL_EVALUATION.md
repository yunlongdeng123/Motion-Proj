# V7.5 反事实评价与有限实验协议

任务 `WS-V75-CF-DEFINITION-01 / 20260921-r1`：定义与执行设计，非模型实验。质量定义及模块图见 [PROBLEM](PROBLEM.md)。不把旧实验重标为反事实验证；执行进度只见 [RESEARCH_STATUS](../RESEARCH_STATUS.md)。

## 参考从哪里来

| 参考 | 能评价什么 | 不能宣称什么 |
|---|---|---|
| 真实配对干预或已知完整合成世界 | 状态、可见性；同策略任务后果；随机环境需重复观测 | 合成参考不自动等于真实世界 |
| 额外观测支持的几何、演员和地图 | 有支持区域的存在、位置、遮挡及事件约束 | 未拍过的新视角摄影真值、完整交互反应 |
| 输入支持的局部约束/配对一致性 | 未改对象身份、合法位置、编辑遵循 | 未知背景内容唯一正确 |
| 无参考、仅观感或模型裁判 | 展示、探索、明显矛盾记录 | 反事实正确性或物理因果真值 |

每个目标/时间段登记可测分母和支持区域。未来帧或额外相机若只评价，禁止流入方法；若供给模型，单列额外信息诊断。记录中有轨迹不等于拍到了移除后的背景。参考与被测生成器不能共用同一有偏预测相互认证。

## 五项指标的落地

| 轴 | 最小读出 | 参考与边界 |
|---|---|---|
| 重放 | 可支持区域的图像差、对象存在/投影与状态差 | 同动作同相机；整体 PSNR 不证明任务正确 |
| 编辑遵循 | 移除后残留/重现；移动后位置、尺寸、身份 | 确认条件进入模型，观测读出独立核验 |
| 无关事实保留 | 未影响对象存在/身份、地图拓扑、共同可见区域变化 | 对齐世界点或相机；遮挡和交互响应不算无关变化 |
| 可见性一致 | 有参考对象的显露/遮挡事件、持续性与时序 | cuboid 可见不等于真实像素可见；几何和图像证据分开 |
| 决策/后果保真 | 同策略相对参考的碰撞/越界/进度/规则偏差及 false-safe/false-unsafe | 单策略偏移不能建立策略排序 |

阈值根据参考误差、真实输入下读出重复性和任务尺度，在读取比较结果前冻结。缺测记未知并保留分母，不改阈值挽救结果。先定义效用 J，再比较 J_sim 与 J_ref 的偏差；无可信 J_ref 时仅报告任务结果，不能称 fidelity。

## 第一项实验：有参考支持的对象移除

这是已执行的有限资格实验，不是 SOTA 普遍失败假设。只选 Actor Removal；没有同时启动移位、ego 横移或多策略榜单。

1. **CPU 来源资格**：只审阅已有两个曝光开发任务，不按生成表现换来源。找 A 遮挡 B/已知静态表面，且 B 或背景有真实可见观测支持的目标。按日志 ID、目标 ID 排序选首个合格者，最多一个。登记合法输入、仅评价和未知信息。两例均不满足就结束来源窗口，记数据缺口；不调用生成器或临时扩充来源。
2. **合法初态**：旧运行复用原始 `initial_rgb` 和图像 embeddings。不能保留画面里的 A，却要求 t=0 删除 A，然后将冲突全归咎重建。先证明能提供与移除后初态一致的参考初帧，否则该静态初态编辑不合格。若研究 t>0 外部移除事件，另行声明事件/时间，不伪装自然运动、不偷偷清空历史。
3. **状态与输入**：冻结 A、受影响区域、参照 B、地图和时间；参考同步移除 A，各重建分支面对同一编辑后世界。先检查状态语义，再核验实际 raster/初帧/text/history。差异未进入现接口，就终止该重建性质的比较。
4. **最小生成矩阵**：资格满足后最多六段，seed42、每段117帧、固定相机/动作。三状态各含未编辑/移除配对：参考结构、合法输入估计、同信息普通框/类别先验。编码等价分支去重，不人为制造差异。GT/LiDAR 单列额外信息上限诊断；其生成视频不是反事实真值。
5. **先状态、后反馈**：先测 A 残留、受支持的 B 显露和无关事实保留。固定相机/动作仅隔离传感器通路，不称闭环。发现有参考支持、状态修复可恢复且普通方法未解释的错误后，才冻结至多三段同 seed 实际反馈及编辑后参考评价，不扫编辑幅度。
6. **停止与确认**：参考结构分支同样失败，先查生成/接口；参考不可识别记证据不足；普通框解决则接受；各状态接近保留负结果，不增强编辑强迫失败。有信号后另立一次新固定来源确认，不把开发任务改称独立测试。

以上是执行前冻结的成本上限和决策顺序。单卡/OOM 即停规则继续适用。

## 执行结果：状态敏感性未复现，发现更前置的图像锚定瓶颈

完整结果见[对象移除报告](ACTOR_REMOVAL_COUNTERFACTUAL.md)。核心分母如下：

| 阶段 | 来源 / 调用 | reference removed | DVGT removed | class-prior removed | 判定 |
|---|---|---:|---:|---:|---|
| 曝光开发发现 | 1 日志；6 段、702 帧 | A=1/10，B=9/10 | A=1/10，B=8/10 | A=4/10，B=4/10 | reference 通过；类别先验候选成立但只属开发信号 |
| 独立来源确认 | 固定 8 日志窗口筛到第 5 个；1 次 DVGT；6 段、702 帧 | A=10/10，B=10/10 | A=10/10，B=10/10 | A=10/10，B=10/10 | reference gate 失败；禁止重建排名 |
| 移除起点机制诊断 | 同一独立源；1 段、117 帧 | 从 f=0 删除仍 A=10/10，B=10/10 | — | — | initial-image anchor supported |
| 中距 G1 搜索 | 新冻结8日志窗口筛到第5个；仅2段reference | unedited A=10/10，removed A=7/10；B=8/10→10/10 | 未调用 | 未调用 | G1失败，DVGT禁止准入 |
| 远距小投影来源窗口 | 下一批固定8日志；0模型调用 | 8/8无合格A→B对象对 | 未调用 | 未调用 | 数据覆盖为空；不放宽门槛 |

独立源的编辑确实进入 raster：三状态在编辑前逐像素相同，f=5 后每臂改变约 1.7–1.9 万个条件像素。DVGT 中心误差为 0.380m，类别先验中心误差 0.447m、朝向差 0.68°；初始投影也合理。reference 同样失败，故不能把输出归因于这些重建差异。

从 f=0 删除 A 时，初始 RGB 仍含 A，这是有意的机制冲突，不再伪装成合法静态反事实。第 4 帧条件编辑区 MAE 为 149.07/255，生成对响应为 8.63/255，即 5.8%；A 仍清晰存在。该诊断支持初始图像锚定，而不是仅由先生成 5 帧后的自回归历史锁定造成。响应比是事后描述量，不是通过阈值。

对象即时移除来源搜索停止。下一类实验应保持初始 RGB 与状态一致，只在未来改变演员轨迹，先运行 reference-only G1；只有 G1 通过，才继续问哪类重建误差改变生成状态。当前不追加同源 seed、事件时刻或编辑强度来挽救确认。

## 输入预算与方法名称

自然重建经额外 GT 尺寸/朝向读出的距离诊断，不称“官方 DVGT 完整可编辑状态”。普通框不是天然弱基线；GT、LiDAR、未来观测、身份和完备合成场景须单列信息。

“Generative-only”仅在官方接口允许且模式可合理运行时比较；置零地图/框可能引入分布外条件，不能直接称公平无重建基线。当前不新增 backbone、训练或接口凑齐方法。

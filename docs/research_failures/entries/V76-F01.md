# V76-F01：COLMAP 无序 image ID 导致 VAD-GS 初始化 track 绑定错误
<!-- metadata: {"title":"COLMAP 无序 image ID 导致 VAD-GS 初始化 track 绑定错误","defined_ids":["V76-F01"],"referenced_ids":[],"versions":["V76"],"topics":["engineering","initialization","visibility","reproduction"]} -->

- task/run：`VADGS-P0-000-COLMAP-AUDIT`、`VADGS-P0-000-TEST-16000`，2026-09-26。
- 类型：已确认的初始化工程失败；不是数值、优化、表示或科学假设失败。
- 触发：上游 `drivestudio_utils.py` 按 image ID 整除/取余推断 camera/frame；本机 COLMAP 模型的 300/305 图像与该顺序假设不符。COLMAP ID 本就是无序标识符。
- 实际影响：旧初始化的 15,756 个 COLMAP 点中，15,754 行 visibility 与名字恢复的真实 track 不一致；59,793 条边只有 3,370 条共同边。相同错误视图索引还用于法线读取。229,879 个背景初始化点中其余 214,123 点来自 LiDAR 等，不把所有点都说成错误。
- 强控制：按 `images.bin` 名字恢复 `(frame,camera)`，与已保存 PLY 尾部坐标/顺序及 NPY visibility 逐点比较；保存值精确复现原错误算术，证实不是只在诊断脚本中的猜测。
- 同期评价：16k 原始官方时间 test 的 75 视图为 PSNR 22.7010 / SSIM 0.7486 / LPIPS 0.2313。相机 5 是全路未见外推；此前相机 0 的 61 帧是混合训练/留出对照。它们都不能拿来判定 VAD-GS 基础重建失败。
- 修复：新增按图像名字连接实际视图表的 helper；3 项针对性回归、305 图像真实映射 0 错配、编译与 diff 检查通过。当前旧 run 未被追溯修复，重训必须重建初始化，不 resume 旧 P0 checkpoint。
- 仍开放：错误绑定具体损失多少画质、sparse 与 exhaustive 对过滤后几何覆盖的差别、修复后的最终收敛和未见相机性能。24.42% 的误差过滤保留率不单独证明 sparse 是低画质的原因。
- 停止边界：停止以该 P0 run 的继续收敛作为方法判决；保留原输入、4k/8k/16k 权重、日志、官方测试与 Camera 5 正反证据。后续先纠正预处理，再评价方法。

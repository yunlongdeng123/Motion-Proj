# V81-F03：DVGT 原生输出的尺度与自车坐标导出适配错误

2026-09-13；task WS-V81-GPU-P2-01。分类：本项目导出实现错误，已修正；不属于DVGT模型failure，也不计入科学badcase。

触发：首轮GPU forward和strict权重加载成功，但DVGT首例4个参考ROI覆盖率为0，大量深度为负。原生points数值有限，不能据此宣布低纹理重建失效。

官方依据：[DVGT代码](https://github.com/wzzheng/DVGT)。固定官方版本的`configs/_base_/default_dataset.yaml`设`gt_scale_factor=0.1`，`DVGT1.post_process_for_eval`按该值除回；`tools/data_process/dataloaders/base_loader.py`给出RDF→FLU矩阵，nuScenes loader保存相机自身时间戳的ego RDF pose，scene dataset取首输入相机的ego pose。本项目原适配遗漏除0.1与RDF→FLU，并错用LIDAR_TOP时间戳的ego pose。

修正：原生points保持原值，按官方固定尺度除0.1，RDF `[right,down,forward]`→FLU `[forward,left,up]`；使用首输入相机ego pose再变换到目标相机z。无需使用GT拟合尺度、无需改权重、无需重跑39项已完成forward。旧深度与旧result保存在`retired_contract_r0`，旧result改名`historical_result.json`防止评价器误收；首轮错误pilot评价仅保留为实现历史。

验证：显式坐标/尺度/相机时间戳测试通过；首例四ROI覆盖率1/1/0.9974/1，MAE分别1.536/1.309/1.274/0.282m。此处只说明合同恢复，ROI仍为DISCOVERY候选。此前7项CPU检查未覆盖官方模型单位约定，不能继续把它们写成完整GPU复现证明。

证据：`/root/autodl-tmp/runs/worldsim_v81/WS-V81-GPU-P2-01/contract_repair.json`、`contract_evaluation`；实现`run_worldsim_v81_inference.py::dvgt_camera_points`与`repair_worldsim_v81_dvgt_export.py`。

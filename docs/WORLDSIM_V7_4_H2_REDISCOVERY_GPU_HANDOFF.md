# V7.4-H2：GPU 接续与可证伪比较

当前状态 CPU_DONE_WAIT_GPU。此计划不是已执行结果，不启动训练或自动调度。

![组件与数据流](figures/worldsim_v74_rediscovery/architecture_components.png)

先测模型是否确有侵入，再判断补全/修复的改进是否付出侵入代价。优先在同一输入、同一对象和真实留出射线上比较，不能把不同场景平均数拼成trade-off。

1. **固定发现窗口。** 先用已有5个nuScenes开发日志，每日志按metadata时间顺序固定2个窗口，共10；本轮3个案例固定保留。新输出前保存manifest、BUILD/QUERY时间、原始图像和标定、静动态/归属标记。它们都是已曝光DISCOVERY，不是论文充分样本或独立确认。
2. **官方方法与输入。** 首批VGGT-1B、Pi3X、MapAnything、DVGT，共4方法×10窗口×6个同步环视输入=40次forward；坐标/尺度pilot先占用其中2窗口，合同未建立不扩队列。各自官方分辨率/预处理，原始数据相同，计算量差异明示。不通过任意单后向相机模式测试DVGT。再补每窗口一个真实相邻时刻，6→12视图，另40次forward，用于同模型补充证据的可恢复性，不预设更多视图必然退化。
3. **直接后继与重建输出。** VGGT-Ω checkpoint访问确认后追加10个6视图结果；先检查官方推荐benchmark版本、数据重叠、分辨率配置，不能用旧512版含混作基准。DGGT另10窗口，官方序列长度/时序要求可能不同，按可比输入单列；保留原生Gaussians、官方渲染/深度和几何诊断。Gaussian alpha合成期望深度不等于不透明首交点；需要明确其传感器读出后才能评价对应假表面。未建立读出合同则报告未测，不能擅自硬化全部Gaussian。
4. **无额外forward的强控制。** 原生深度/点图直接检查；原生位姿和已知标定对照；仅BUILD LiDAR全局定尺度单列额外信息诊断；固定普通置信过滤保留比例100/90/75/50%形成覆盖—Early曲线；图像网格三角化需深度断边，固定不同合法读出比较表面化增量，保留原生分支。采样邻域、置信分位及断边参数在读取本批QUERY结果前冻结；不能挑最坏阈值。静态、动态和边界分别计数。
5. **确认与停止。** 原生残余在多个发现日志仍存在且参考可靠，才冻结失败定义并登记独立新日志；按日志计算配对区间和同时改变的联合事件比例。至少一次普通尺度/读出控制后仍存在残余，才支持模型级缺口；“为了补全而付出侵入代价”还须同模型配对干预。若仅自定义读出失败，则把claim收窄为读出；若成熟普通控制同时修复几何/物理，则保留成功并降低研究优先级。没有证据时不增加更极端合成条件。

任务上限：首批40＋真实额外观测40；Omega最多10、DGGT最多10，共最多100次forward。权重或接口未就绪的方法记录未测，不以其他模型代替；不追加训练。小批只确定是否值得做正式研究，不能推出所有SOTA都有缺陷。

建议资源：**2×RTX3090/4090 24GB**，每卡一个独立模型worker、各自顺序队列，不做跨卡训练。1张24GB也可串行先跑6视图；DGGT/12视图和具体分辨率先量显存，不能承诺任意长序列都能装下。主机至少32GB内存，建议64GB、4核以上；当前0.5核/2GB不足以加载这些主模型。无需4/8卡。当前未关机、未设置自动续跑。

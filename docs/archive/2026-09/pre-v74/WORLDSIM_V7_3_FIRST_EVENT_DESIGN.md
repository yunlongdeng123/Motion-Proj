[DS-NeRF（CVPR 2022）](https://www.cs.cmu.edu/~dsnerf/)已监督射线终止深度分布并纳入深度不确定性；[Depth-guided NeRF Training via Earth Mover’s Distance（ECCV 2024）](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/8062_ECCV_2024_paper.php)也已研究对终止距离分布用EMD监督。因此，本轮不把终止分布损失本身称为创新，也不把换成EMD等同于解决无几何支持的梯度问题。

候选几何定义沿用已实现的显式三角面。对固定有限射线管的每个横向采样位置a，取同一表面的最近正交点d(a)，无交点为∅；固定归一化footprint权重w(a)给出终止深度分布及no-return质量。这里的分布来自几何和固定测量代理，不再设置每个primitive独立opacity、存在性或可学习光束半径。同一位置复制三角面不增加独立命中机会，被前面表面遮挡的后面三角面不能提供该a的返回概率。

对唯一Actor归属的真实首返回d*，定义相对于高斯峰值的likelihood score：

    s(d*) = Σ_{a: d(a)≠∅} w(a) exp(−(d(a)−d*)²/(2σ²)),   0 ≤ s ≤ 1。

除去与参数无关的高斯归一化常数，−log s是该几何返回混合的NLL。对应的no-return质量由未命中的footprint部分给出，不能把“文件没有保存某条无返回束”当作真实no-return训练标签。背景/其他Actor的原始首返回只进入本Actor的free约束，不用其d*要求当前Actor生成背景表面。

射线管的深度范围必须由当前几何/只读空间范围确定，不按d*裁掉早面、只保留target附近面或在训练时挑最接近target的交点。目标仅进入监督分布。后续场景评价仍用中心束在全部Actor和背景上的全局硬排序，训练代理不能取代它。

严格NLL在s=0时为+∞。有限footprint外没有面时，单纯log-domain计算或降低温度不会产生位置梯度。不能先丢弃未命中束，再在剩余束报告NLL下降。为实际优化考虑的首个控制是明确标为“截断NLL代理”的min(−log s,C)，全体有真实Actor首返回的束都进入均值，s=0取同一上界C。相同截断也施于已有支持但严重错误的返回，避免无支持反而比极差支持获得更低的event损失。截断只是有界优化代理，不是给几何添加ε透射率，也不是严格概率似然；严格无支持计数、截断比例和真实hard miss必须另报。

该代理在无支持和截断区仍可能为零梯度。因此必须保留全部真实正观测到生成表面的直接覆盖吸引，以及独立、不因置信度下降而减轻的free惩罚。不能声称event单项解决支持生成；如果加入event后覆盖塌缩、无支持增加或只有代理下降，保留负结果并调整支持/目标，而不隐藏分母。也不把沿射线的高斯残差鲁棒化用于截断危险的free侵入。

实现时优先复用[nvdiffrast官方原语](https://nvlabs.github.io/nvdiffrast/)：最近三角面、米制深度属性插值、对预乘几何覆盖的likelihood做轮廓antialias，随后固定footprint积分。在每条束上用停止梯度的log平移稳定指数与求和；未覆盖像素先置零贡献，避免无效指数乘零产生NaN。禁止对带有无穷或任意背景深度的log值直接antialias。该轮廓梯度仍是有限分辨率代理，不能称精确硬射线梯度。

首轮可用固定σ=0.2m、C=28、footprint宽度0.03m作为开发起点；这些是现有容差尺度附近的优化假设，尚无传感器标定依据，也不预设最终最优值。先固定一个架构/free目标，只比较event=0与一个适中权重；不同时改变σ、查询结构和支持数量。若要用延拓或EMD，必须由这个机制比较的失败现象决定，避免一次叠加多个无法归因的变化。实现后只做一次针对前后遮挡、无支持与重复面语义的解析验证，再进入实际训练。

# V7.3：表面参数化候选的源码迁移边界

状态：2026-09-08；代码阅读基于项目944d6904及当日可访问的官方源码。本轮完成接口与梯度路径分析，尚未实现、训练或选定DMTet/FlexiCubes。R12/R14继续原配置，三角收口后的条件决策保持。

当前同监督诊断表明：R10相对R7多12.949pp“表面邻近但没有正确沿束交点”，五日志均增加；相对R11却增加16.055pp正确沿束支持，五日志均改善。这使位置、局部片形状/方向及片间结构成为待辨别因素，但未证明换成某种网格就能解决。原始证据见[固定表面支持诊断](WORLDSIM_V7_3_SURFACE_SUPPORT.md)。

## 当前组件与替换位置

![当前已实现的几何生成与物理读出组件](../../../../paper_v73/figures/architecture_components.png)

图为已有实现。`ActorSpatialQueryDecoder.forward`保留可训练DPT中间特征、米制投影和三轮空间查询；当前输出是每query一个3×3高度片、8个三角形。位置更新不受初始点邻域锁定，法向来自可学习头加径向方向，9个高度偏移独立预测，片间没有共享顶点。新候选应在“查询隐状态→显式表面”处改变形状/连接参数化，继续输出`vertices_actor_m`和`faces`供同一物理读出使用。

现有trainer的coverage直接查询三角面；当没有面时coverage归零。原生build深度数据项可以继续更新DPT，但这不等于空表面的生成参数已经获得位置梯度。应分清几何基座有梯度、表面参数有梯度、真实支持实际出现这三件事。

## 官方实现给出的边界

| 路径 | 可迁移组件 | 源码确认的限制 |
|---|---|---|
| DMTet式可变四面体 | 网格顶点、标量场、异号边插值与显式三角面 | 活跃四面体/异号边的离散筛选不参与反向；插值对选中位置与标量可微 |
| FlexiCubes | 共享格点/单元形成的对偶表面，位置与形状权重 | 无异号单元时返回空网格；提取模式和三角划分需要明确 |
| 当前独立高度片 | 直接顶点位置梯度、已有查询生成通路 | 片内连通不代表片间连贯；正确邻近覆盖不保证沿束支持 |

Kaolin的`marching_tetrahedra`在`no_grad`内根据角点符号筛选四面体与边，随后插值生成顶点；因此可微提取不能直接等同“任意空区域都有表面损失梯度”。这里核对的是提取算子，不是复现原DMTet整套生成网络。[Kaolin源码](https://raw.githubusercontent.com/NVIDIAGameWorks/kaolin/master/kaolin/ops/conversions/tetmesh.py)、[API文档](https://kaolin.readthedocs.io/en/latest/modules/kaolin.ops.conversions.html#kaolin.ops.conversions.marching_tetrahedra)。

FlexiCubes同样用离散符号识别活跃单元；全无活跃单元时返回空张量。默认优化路径通过插值与权重定位表面；提供`grad_func`的QEF路径被实现为不可微提取，不能作为这里的训练通路。其`training=True`为四边形增加中心点并分成四面，`False`按权重选对角线分成两面。[FlexiCubes核心源码](https://raw.githubusercontent.com/nv-tlabs/FlexiCubes/main/flexicubes.py)。

官方优化示例从随机混合符号开始，以参考完整网格渲染的mask/depth训练，并包含网格正则和可选的参考SDF监督；它在训练时使用四分片，保存时切换为两分片。这些观测条件与V7.3稀疏真实返回不同，不能照搬其完整内部符号标签。[官方优化示例](https://raw.githubusercontent.com/nv-tlabs/FlexiCubes/main/examples/optimize.py)。

官方还明确提醒，两个项目的同名grid resolution并不代表相同顶点数、三角面密度或成本；旧示例环境只是其示例依赖，不构成本项目必须复制的运行环境。[官方说明](https://github.com/nv-tlabs/FlexiCubes#resolution-of-voxel-grid-vs-tetrahedral-grid)。本轮没有安装环境或下载权重，未测这两个候选在本项目上的峰值显存或耗时。

## 对V7.3迁移的具体推论

以下是结合源码与当前监督的设计推论，尚无V7.3实验收益：

1. **缺支持恢复要保留独立路径。** 若选择共享标量场，不能只把当前coverage/free/event接到提取后网格，便宣称解除F03；同号空单元并没有由该网格损失直接提供的出生梯度。可考虑从build几何产生初始支持、保留可生成粗支持，或让可靠表面/已观测自由证据直接监督场参数。后一项会改变监督实现，须明确披露并单独解释，不能称为只换head的纯参数化对照。初始形状先验不是GT，未观测区域及首返回后方不补成FREE/占据厚层。标量场也不未经约束就称为准确米制SDF。

2. **训练与物理读出应使用同一张显式表面。** FlexiCubes的四分片和两分片在非共面时可能覆盖不同位置，硬首交点可能变化。若采用它，可优先让训练与评价均输出同一种四分片几何；评价用`no_grad`关闭反向，不把它误当作必须切换提取模式。若选择最终两分片导出，应把转换造成的差异单列，不能算成基础模型或物理损失本身的错误。该取舍待候选确定后实施。

3. **网格分辨率不能隐含扩大跨视图查询。** 不默认让每个稠密格点都运行24视图局部attention。可先保留有容量的三维查询，再向共享格点局部传递隐状态；这会增加真实三维支撑与连接，但其插值、激活和网格提取成本仍需在实际候选中测量。比较应记录真实格点/单元/输出面数量及米制间距，不能拿相同resolution名称当同预算。资源由实现测量决定，不先削减现有时空输入来适配24GB。

4. **结构连贯不自动消除幻觉。** 共享单元和统一顶点能改变片间连接组织，但没有自动排除额外壳层、错误首表面或未知区错误形状的保证。现有owned支持诊断也没有完整解释全部near-box free与背景拼接；继续使用直接几何/free及同一硬读出。不要把官方去浮层正则、所有SDF监督、near-surface项和新attention一次叠加后归因给网格表示。

若三角仍存在coverage/physics冲突，依据最终R12/R14及当前诊断在连贯曲面参数化中选一个可执行候选；DMTet式提取接口较简单，FlexiCubes有更多几何自由度与模式取舍，二者目前均为候选。若发现所需符号/支持恢复必须依赖无法获得的监督，则优先考虑直接显式共享顶点的曲面参数化，保持可训练基座与生成能力，而不是退回native-only。此处只列迁移首选条件与替代，不新增实验队列或晋级门控。

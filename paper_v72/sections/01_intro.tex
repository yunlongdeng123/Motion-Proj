\section{Introduction}
Existing actor insertion pipelines can produce visually plausible point sets while
violating the sensing process that generated them. A useful simulator must distinguish
an invalid query, a censored ray, a valid no-return, background occlusion, and an actor
return. It must also make predictions from build-time evidence alone. This draft centers
the paper on that task definition and delays method claims until matched baselines are
available.

The planned contributions are: a target-free dynamic LiDAR query contract; a shared
surface-to-return operator with explicit visibility states; and a matched evaluation
matrix spanning raw fusion, geometric completion, a legacy learned model, and an
external completion baseline. These contributions remain provisional until the D0 gate.

\section{Method}

\subsection{Canonical Evidence and Immutable Actor State}

For Actor $i$ at time $t$, annotated sensor, ego, and Actor poses map a LiDAR endpoint into a canonical coordinate system,
\begin{equation}
x_{i,t}=T_{i,t}^{-1}T_{\mathrm{ego},t}T_{\mathrm{sensor}}x_t^{\mathrm{sensor}}.
\end{equation}
Build sweeps provide model input; disjoint held-out sweeps construct the target $T_i$ and are never input features. Directly
observed and matched projected endpoints form an immutable anchor set $A_i$. Actor identity, trajectory, extent, lifecycle,
and hazard label are immutable interfaces rather than prediction targets.

For a held-out ray $r=(o,v,d^\star)$ and physical surface $S$, the literal first return is
\begin{equation}
d_S(r)=\min\{s>0:o+sv\in S_\epsilon\},\qquad \min\varnothing=\infty.
\label{eq:first-return}
\end{equation}
An early return satisfies $d_S(r)<d^\star-\epsilon$. Deletion can only make this predicate non-increasing, but may destroy
hits and surface coverage. We therefore do not treat a lower early-return rate as sufficient evidence of consistency.

\subsection{Supervision-Native Child Surfaces}

One completion seed cannot cover a dense target surface. Each seed $x_j$ predicts four bounded Actor-frame residuals and
positive support scales,
\begin{equation}
x'_{jk}=x_j+\Delta x_{jk}(E_i),\qquad
S_i^\theta=A_i\cup\{(x'_{jk},s_{jk})\}_{j,k=1}^{4},
\label{eq:child-surface}
\end{equation}
where $E_i$ contains build-only geometric and ray evidence. Geometry pretraining combines bidirectional set distance,
target-local point-to-plane distance, and a target-spacing scale loss. Physical fine-tuning keeps these terms active and adds
frame-balanced target coverage, differentiable literal first return, and observed free-before-hit supervision:
\begin{equation}
\mathcal L_{\mathrm{phys}}=
\mathcal L_{\mathrm{set}}+.25\mathcal L_{\mathrm{plane}}+.1\mathcal L_{\mathrm{scale}}
+\mathcal L_{\mathrm{frame}}+\mathcal L_{\mathrm{first}}+.5\mathcal L_{\mathrm{free}}.
\label{eq:physical-loss}
\end{equation}
Space behind the first hit is not labeled free. Every child remains in $S_i^\theta$ at deployment; UNKNOWN is evidence state,
not a mask. Thus an improvement must arise through the supervised representation rather than selective output removal.

\subsection{Producer-Evidential Return Authority}

Surface support and sensor termination are distinct. For each anchor or child $j$, the build descriptor $e_j$ retains source
ray/frame identity, construction provenance, projection displacement, canonical hit count, temporal/view support, and
continuous build evidence $m_j^{\mathrm{build}}=(m_F,m_O,m_U)$. Disjoint target rays construct
$m_j^{\mathrm{GT}}$ from free evidence before a return, occupied evidence near it, and unknown evidence behind it or outside
ray support. A bounded head predicts $m_j=f_\phi(e_j)$ and is supervised by soft three-state cross-entropy. Completion children
also receive the GT free-before-hit event loss used by the deployed ray objective. Geometry is frozen during this authority stage.

Let $o_j$ be predicted occupied mass and $\kappa_{kj}$ the frozen Gaussian support of primitive $j$ at ordered depth $d_k$.
Instead of adding $o_j\kappa_{kj}$ as density-dependent opacity, we define one joint categorical return measure,
\begin{equation}
q(k,j)=\frac{o_j\kappa_{kj}}{\sum_{a,b}o_b\kappa_{ab}},\qquad
p_k=\sum_jq(k,j),\quad F_k=\sum_{\ell\le k}p_\ell.
\label{eq:categorical-return}
\end{equation}
The deployed return is the median, $\widehat d=\min\{d_k:F_k\ge1/2\}$. Training and deployment use the same ordered
distribution. Normalization guarantees non-negative unit mass and a monotone CDF, but does not turn $o_j$ into occupancy or
collision probability. The current protocol conditions on one return inside the Actor box and does not model ray drop.

For boundary $b=d^\star-\epsilon$, piecewise-linear interpolation gives the exact deployed decision
\begin{equation}
\widehat d<b\quad\Longleftrightarrow\quad F(b)>\tfrac12,\qquad
F(b)=F_{\mathrm{anchor}}(b)+F_{\mathrm{child}}(b).
\label{eq:categorical-safety-boundary}
\end{equation}
This decomposition explains responsibility but is never used to delete a primitive or case.

\subsection{Typed Motion and Appearance Ownership}

Rigid pose is a separate read-only authority. With $T_{it}=(R_{it},t_{it})$, the physical query is
\begin{equation}
Q_{it}(x;P_i,T_{it})=
\log\sum_j\exp\!\left[-\frac{\|R_{it}^{\top}(x-t_{it})-c_{ij}\|_2^2}{2s_{ij}^2}\right],
\label{eq:authority-query}
\end{equation}
where $P_i=\{(c_{ij},s_{ij})\}_j$ is canonical physical state. Static Background is a separate scene component. Visual state
$V_i$ contains render geometry, SH, and opacity; image optimization receives $\operatorname{sg}(P_i)$ and updates only $V_i$.
Consequently $\partial Q_{it}/\partial V_i=0$, and for a common rigid transform $g$, inverse querying yields
$Q_{gT}(gx)=Q_T(x)$. These are ownership and equivariance guarantees, not guarantees that pose or geometry is correct.

\subsection{Finite Attenuation Boundary}

The normalized measure also identifies when learned visibility is unsafe. For primitive $j$, let
$D_j=\sum_k\kappa_{kj}$, $N_j=\sum_{d_k<b}\kappa_{kj}$ with boundary interpolation,
$C_j=N_j/D_j$, and $r_j=o_jD_j/\sum_a o_aD_a$. Direct differentiation gives
\begin{equation}
\frac{\partial F(b)}{\partial\log o_j}=r_j\bigl(C_j-F(b)\bigr).
\label{eq:attenuation-sign-boundary}
\end{equation}
For any finite attenuation $v\in(0,1]$ applied to the component, or to a family treated as one component,
\begin{equation}
F_v(b)-F(b)=\frac{(1-v)r_j\bigl(F(b)-C_j\bigr)}{1-(1-v)r_j}.
\label{eq:finite-attenuation-boundary}
\end{equation}
Attenuation lowers the pre-boundary CDF iff $C_j>F(b)$; changing its magnitude cannot reverse the sign. Because $b$ uses
target depth, this is an explanation and model-design boundary, not a deployable oracle gate.

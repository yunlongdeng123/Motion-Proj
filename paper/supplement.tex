\section{SceneIR Schema and Coordinate Conventions}

SceneIR records explicit $T_{\mathrm{city}\leftarrow\mathrm{ego}}$,
$T_{\mathrm{ego}\leftarrow\mathrm{sensor}}$, and
$T_{\mathrm{city}\leftarrow\mathrm{actor}}$ transforms. A return $x_{s,t}$ is fused in Actor coordinates as
\begin{equation}
x_i = T^{-1}_{\mathrm{city}\leftarrow\mathrm{actor},t}
      T_{\mathrm{city}\leftarrow\mathrm{ego},t}
      T_{\mathrm{ego}\leftarrow\mathrm{sensor},t} x_{s,t}.
\end{equation}
The physical layer stores Actor-local surfels, known/unknown masks, normals, temporal and view support, matched rays, and source
timestamps. Appearance primitives are referenced only through attachment provenance; Gaussian opacity is never read as collision
occupancy. Actor identity, category, extent, trajectory, lifecycle, and analytic hazard fields are immutable across compiler actions.

\paragraph{Four actions.}
\textsc{Keep} preserves supported query evidence. \textsc{Project} moves an artifact only to its matched observed termination.
\textsc{Complete} adds a canonical surfel only when temporal and view support satisfy the frozen contract. \textsc{Unknown} is the
fallback when evidence is insufficient; it never becomes free.

\section{Matched-Ray Physical Certificate}

Automotive LiDAR is 2.5D ray evidence, not merely an unordered 3D point set~\cite{hu2020visibility}. For origin $o$, direction
$v$, and observed termination $d$, the measured free interval is
\begin{equation}
\mathcal F(o,v,d)=\{o+sv\mid 0\leq s<d-\epsilon\}.
\end{equation}
A provenance-bearing \textsc{Project} candidate is placed at the same ray's termination $o+dv$. It therefore cannot lie in
$\mathcal F$. A candidate without an exact ray is marked \textsc{Unknown}; nearest-surface projection is not substituted. This is
the source of the paired zero-free-space result. It is a deterministic contract for matched rays, not a completeness proof for the
whole Actor surface or a probabilistic sensor-noise guarantee.

The held-out targets are later frames excluded from both canonical fusion and query compilation. Depth, ray-termination, Chamfer,
precision, and recall are computed against these target-only returns. This separation explains why zero paired free-space violation
can coexist with the observed \PthreeActorWorse{}\% per-Actor Chamfer tail.

\paragraph{Bidirectional visibility partition.}
For each held-out target ray, the nearest output within the frozen $0.20$\,m beam tube is classified as early, hit, or late;
otherwise it is unmatched. In the reverse direction, an output point is supported at the first return, contradicted if it lies in
the observed free interval, occluded if it is behind the return, and unknown when off ray. Occluded and unknown points are not
penalized as free-space violations, preventing unseen Actor backs from being conflated with measurable contradictions.

\section{Actor-Level Decision Intervals}

For the frozen ReLU validity MLP, an input box $[\ell,u]$ is propagated through each affine layer using
\begin{align}
\ell' &= W^+\ell + W^-u + b, &
u' &= W^+u + W^-\ell + b,
\end{align}
followed by endpoint-wise ReLU. Here $W^+=\max(W,0)$ and $W^-=\min(W,0)$. The resulting logit interval is mapped through the
sigmoid. An Actor is \emph{robust-select} if its lower probability is above the frozen P4 threshold, \emph{robust-abstain} if its
upper probability is below threshold, and unresolved otherwise. This is deterministic interval-bound propagation over a specified
box, related to robust-OOD certification~\cite{bitterwolf2020certifiably}; it does not assert that the box describes an unseen sensor.

We fix radii $0.05/0.10/0.20$ in nuScenes-training standard deviations. The sensor-opportunity group contains point/surfel counts,
temporal/view support, range, and frame count; the physical-surface group contains surface residuals, keep/unknown fractions,
completion fraction, and compiled/query ratio. Their union is exactly the 13D validity input.

At radius $0.10$, \PsevenCTestCertified{}\% of nominal nuScenes-test selections and \PsevenCAVCertified{}\% of consumed-AV2
selections are robust-select. Nevertheless, \PsevenCAVStableFalse{}\% of the latter are retained target false repairs. Query-point
count is the largest one-feature interval source for \PsevenCTestQueryTop{}\%/\PsevenCAVQueryTop{}\% of nuScenes/AV2 Actors.
Thus a shifted model can be confidently and locally stable while wrong.

\section{Resource and Reproducibility Boundary}

All V7 scientific runs use one RTX~3090. The largest paper-facing GPU allocation is below 1.5\,GiB, while P7-C uses 9.2\,MiB and
1.37\,s. Download and preprocessing are sequential on the low-memory host. Artifacts are identified by task/run paths and immutable
cohort/config files; the protocol intentionally does not add hashes, checksums, fingerprints, repeated smoke matrices, or post-hoc
quality gates.
